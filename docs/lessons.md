# 배운 점·막혔던 곳

## 설계
1. **같은 모델 여러 개 ≠ 다양성.** 에이전트 수가 아니라 설계 원칙을 다르게 줘야 후보가 갈린다.
2. **만든 쪽이 채점하지 않게.** 채점 기준은 샘플을 보기 전에 다른 에이전트가 만들고, 응시자는 샘플 1개 + 시험지만 볼 수 있게 파일을 제한했다.
3. **시험이 변별력이 없을 수 있다.** 샘플이 연습문제를 많이 넣으면 예상문제를 "덮어 버린다." 다음엔 샘플이 직접 풀어 주지 않는 응용·해석 문제를 섞을 것.
4. **AI 점수 ≠ 사람의 선호.** AI 1등은 B였지만 사용자는 D를 골랐다. 본인 평가 칸(30%)을 비워 두고 사람이 정하게 한 것이 맞았다.
5. **감사 지적을 다음 버전 규칙으로.** 공통 약점(앞 장 기초 없음, 기호 혼용, 분량)을 v1.1/v1.2 규칙으로 고정하니 장별 에이전트가 같은 실수를 반복하지 않았다.
6. **원본 오류는 고치지 말고 표시.** "고친" 교재는 강의·시험과 어긋난다. 원본 표기 + "(직접 계산하면 …)"으로 둘 다 보이게.

## 기술적으로 막혔던 곳
| 문제 | 해결 |
|---|---|
| 교재 3권이 스캔 PDF (텍스트 없음) | 페이지를 이미지로 렌더 → 썸네일 몽타주로 목차 찾고 필요한 쪽만 고해상도 |
| 강의 슬라이드 수식·표가 그림에만 있음 | 텍스트 추출 + 슬라이드 이미지 전부 직접 보기, 작은 표는 150dpi 재렌더 |
| 클라우드 작업 공간에서 이클래스 파일 서버로 직접 다운로드 불가 | Composio 작업대에서 받아 zip → 맥 앱 브라우저로 내려받기 → 맥 폴더에서 다시 가져오기 |
| 여러 에이전트가 같은 임시 폴더에 `p1.md`를 써서 덮어씀 | 실행 중에 장별 전용 하위 폴더 지시 메시지 |
| pandoc이 `::: name key="v"` 를 div로 못 읽음 | 전처리로 `::: {.name key="v"}` 변환 |
| 문단 바로 다음 줄의 `:::` 가 문단 글자로 흡수됨 | 전처리에서 모든 펜스 앞뒤에 빈 줄 |
| reportlab이 한글 CFF 폰트를 못 넣음 | 세로띠·쪽 번호도 Chrome으로 오버레이 PDF를 만들어 pypdf로 겹치기 |
| 노션: 한 줄짜리 `$$…$$` 깨짐, 첫 `#` 제목 사라짐, 이어 붙이기 도구 없음 | `$$` 줄 분리, 제목 재삽입, 마커 줄 바꿔치기로 append |
| 차례 쪽 번호가 1쪽 어긋남 / 세로띠가 "시험 대비 팩"을 언급만 한 쪽에서 바뀜 | 쪽 번호 기준 재계산 / 쪽 맨 앞 제목일 때만 전환 |
