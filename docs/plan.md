# 처음 계획과 검토

## 처음 계획 (김준엽, 2026-11-11)

**목적**
- 통계와 사회 과목 강의자료로 기말고사 공부를 하기 위함
- 교수가 올려놓는 강의자료 원본은 학습에 도움이 안 됨
- 시중에 가장 유명한 수학 개념서의 개념 구성·서술·배치 방식을 벤치마킹해서 '통계와 사회' 공부용 개념서를 제작

**이용할 자료**: 개념때려잡기 확통 / 개념 때려잡기 미적분 / 2022 개정 시발점 확률과 통계 + 통계와사회 강의자료 전체

**파이프라인**
1. Claude 에이전트 5개 이용 (개수는 추후 조정)
2. 5개가 각각 3개 교재를 학습 (내용보다 형식, 개념 구성 방식에 집중)
3. 각 에이전트가 좋은 방식들을 통합해 교재 구성 형식을 구현
4. 각각 Test 실행 → 가장 높은 점수의 형식으로 PPT를 교재화

## 검토에서 바꾼 것

| 처음 계획 | 문제 | 바꾼 것 |
|---|---|---|
| 에이전트 5개가 같은 3권을 모두 학습 | 같은 모델·입력·지시면 결과가 수렴해 다양성이 안 나옴 | 1단계는 **교재 1권당 1개**로 분석만, 2단계에서 **설계 원칙을 다르게 준** 후보 4개 |
| "Test" 정의 없음 | 승자를 고를 근거가 없음 | 샘플을 안 본 에이전트가 만든 **개념 체크리스트 + 예상문제 + 채점표**, 응시·감사 에이전트 분리, 본인 평가 30% |
| 수백 쪽 PDF를 통째로 읽음 | 비용·시간 | 목차·사용법·대표 단원 2개만 |
| 고교 수학 교재 형식을 그대로 이식 | 교양 통계는 해석·사례 비중이 큼 | 시험 역산형·혼합형 후보 추가, 표 읽기·해석 틀 장치 |
| 기존 도구와 분리 | 재사용 불가 | course-study-pipeline 템플릿으로 등록하는 5단계 추가 |
