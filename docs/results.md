## 형식 테스트 (테스트 단원: 제7장 확률표본과 추정 + 7장보충, 원본 45쪽)

| 항목 | 만점 | A 시발점형 | B 개때잡형 | C 시험역산형 | D 혼합형 |
|---|---|---|---|---|---|
| 누락 (개념 99개 대비) | 25 | 25 | 25 | 25 | 25 |
| 시험 대비력 (12문항) | 30 | 29.8 | 30.0 | 30.0 | 30.0 |
| 이해 용이성 | 15 | 10.1 | **11.6** | 10.5 | 9.4 |
| 정확성 감점 | −10 | −2 | **0** | −4 | **0** |
| **AI 채점 합계** | 70 | 62.9 | **66.6** | 61.5 | 64.4 |
| 본인 평가 | 30 | | | | **선택** |

### 해석
- **누락**: 네 형식 모두 개념 99개를 하나도 빠뜨리지 않았다 → 공통 지시(누락 금지 + 자체 대조)가 잘 작동.
- **시험 대비력은 변별하지 못했다.** 샘플들이 자체 연습문제를 많이 넣어서 예상문제와 거의 같은 문제가 샘플 안에 있었다. 형식을 가르려면 샘플이 직접 풀어 주지 않는 응용 문제가 필요.
- **승부는 이해 용이성과 정확성**에서 났다. 네 형식 공통 약점: 앞 장 기초(E, Var, 표준화, 이항분포)를 안내 없이 씀 / 정의보다 용어가 먼저 / 기호 혼용 / 분량·반복 과다 / 자체 규칙을 원본처럼 서술.
- **AI 1등(B)과 사람의 선택(D)이 달랐다.** D는 태그가 많아 "시끄럽다"는 감사 지적으로 이해 용이성 점수가 낮았지만, 사용자는 D의 구성(시발점식 정리→REMARK 리듬 + 시험 대비 장치)을 골랐다. → 본인 평가 30%를 남겨 둔 이유.
