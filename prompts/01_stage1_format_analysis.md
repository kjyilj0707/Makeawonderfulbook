# 1단계 — 교재 형식 분석 (에이전트 3개, 병렬)

교재 1권당 에이전트 1개. 세 프롬프트는 담당 교재와 "집중할 점"만 다르고 나머지는 같다.
공통 지시서는 [00_BRIEF.md](00_BRIEF.md).

| 에이전트 | 담당 교재 (스캔 PDF) | 집중할 점 | 출력 |
|---|---|---|---|
| 시발점 확통 | 2022 개정 시발점 확률과 통계 (259쪽) | 통계 파트 대표 단원 2개 + 확률 파트 1단원으로 공통 패턴 확인 | `specs/spec_시발점.md` |
| 개념때려잡기 확통 | 개념때려잡기 확통 (314쪽) | 위와 같음 | `specs/spec_개때잡_확통.md` |
| 개념때려잡기 미적분 | 개념 때려잡기 미적분 (412쪽) | 같은 시리즈 확통판과 겹치지 않게: 시리즈 공통 형식 + 유도·증명 처리, 그래프 해석, 개념 간 연결 | `specs/spec_개때잡_미적분.md` |

## 프롬프트 (시발점 예시)

```
먼저 /home/claude/proj/BRIEF.md 를 읽어라 (프로젝트 목적·파일 위치·저작권 원칙).

너의 담당 교재: …/2022 개정 시발점 확률과 통계.pdf (스캔 이미지 PDF, 259쪽).
할 일: 이 교재의 **형식(구성 방식)** 을 분석해 "형식 명세서"를 쓴다. 내용(수학 지식)이 아니라 형식에 집중.

절차
1. -r 25 썸네일 몽타주(한 장에 12~20쪽)로 앞부분을 훑어 표지·머리말·교재 사용법(구성과 특징) 페이지·목차를 찾는다.
   사용법 페이지는 고해상도(-r 80)로 자세히 본다.
2. 목차에서 통계 파트(확률분포 / 정규분포 / 통계적 추정 단원)를 찾고, 대표 단원 2개를 처음부터 끝까지 본다(-r 60~80).
   확률 파트도 한 단원 정도 훑어 공통 패턴을 확인.
3. 아래 양식으로 specs/spec_시발점.md 를 작성한다.

명세서 양식
- 0. 교재 한 줄 정체성
- 1. 전체 구조: 대단원 → 중단원 → 소단원 계층, 단원 시작/끝 페이지의 장치
- 2. 소단원 1개의 블록 순서 (블록 이름, 역할, 분량, 레이아웃 위치) — 표로
- 3. 개념 서술 방식: 직관 먼저 vs 정의 먼저, 문장 톤·길이, 비유·그림, 증명/유도 처리, 학생 질문을 예상해 답하는 장치
- 4. 예제·문제 설계: 종류, 난이도 계단, 풀이 표기 방식, 문제와 개념의 연결 표시
- 5. 시각 장치: 박스 종류, 색·아이콘 체계, 도식·그래프 사용법, 여백(필기 공간)
- 6. 복습·정리 장치: 단원 끝 정리, 개념 체크, 오개념 경고, 연결 개념 표시
- 7. 이 교재만의 강점 Top 5
- 8. 약점·대학 교양 통계 교재화에 옮기기 어려운 점
- 9. "통계와사회 PPT를 이 형식으로 바꾼다면" 적용 규칙 10개
- 부록: 본 페이지 목록

주의
- 교재 문장·문제·그림을 옮기지 마라. 구조와 장치만 기록. 인용은 10단어 이내 3번 이하.
- 렌더한 이미지는 work/시발점/ 아래에.
- 다 쓰면 명세서 파일 경로와 핵심 요약 5줄만 최종 답으로 돌려줘.
```

## 같은 시간에 돌린 채점 준비 에이전트 (샘플을 보지 않음)

```
너는 독립 평가 준비 담당이다. 나중에 여러 형식으로 만든 "제7장 교재 샘플"을 채점할 기준을 미리 만든다.
샘플은 아직 없고, 너는 샘플을 보지 않는다.

입력: 7장·7장보충 원본 텍스트 + 슬라이드 그림 45장 (수식이 그림에만 있으니 모든 슬라이드를 직접 본다)

만들 것 (eval/)
1. concepts.md — 채점용 개념 체크리스트. 정의·정리·공식·조건·예제·표/그래프 해석 포인트를 원자 단위로, ID(C01..)와 출처.
2. exam.md — 예상문제 12개 (O/X 3, 객관식 3, 계산 4, 서술형 2). 정답·채점 포인트는 exam_key.md 에 따로.
3. rubric.md — 누락 25 / 시험 대비력 30 / 이해 용이성 15 / 정확성 감점(-2, 최대 -10) / 본인 평가 30 의 환산식.

이 파일들은 샘플 제작자에게 보여주지 않는다.
```
결과: 개념 99개(C01–C99), 예상문제 12개(35점 만점), 채점표 → [eval/rubric.md](../eval/rubric.md).
(concepts.md / exam.md 는 강의 내용을 그대로 담고 있어 레포에 넣지 않았다.)
