# 2단계 — 후보 형식 4개로 7장 샘플 제작 (에이전트 4개, 병렬)

공통 지시서: [02_DESIGN_BRIEF.md](02_DESIGN_BRIEF.md).
"에이전트 5개가 같은 교재를 읽으면 같은 결과로 수렴한다"는 검토 결과에 따라, 에이전트마다 **설계 원칙을 다르게** 주었다.
각 프롬프트는 `DESIGN_BRIEF.md 를 읽고 그대로 수행하라. 너의 형식코드는 **X**.` 다음에 아래 설계 원칙 한 단락을 붙인 것이다.

## A_시발점형
> 시발점 명세서를 중심으로. 상황·직관 → 유도 → 정의 서술 → "정리하면" 공식 박스 → REMARK(문제에서 어떻게 쓰는지·오해 교정) → 풀이가 붙은 [예] 의 촘촘한 계단. 단원 첫머리 개념 흐름도와 "현재 위치" 표시, 소단원 끝 예제(풀이 접기). 다른 두 명세서의 장점은 이 뼈대를 해치지 않는 범위에서만 보조로. (명세서가 지적한 시발점의 약점 — 풀이 부재, 장 끝 요약·오개념 체크 부재 — 은 보완하라.)

## B_개때잡형
> 개념때려잡기(확통·미적분) 명세서를 중심으로. 개념 연번 + THEME 분할, 짧은 도입 → 정의 → 그림 주석 → ◎ 핵심 박스 → Tip(공식 한 줄·암기 구호) → 시범예제(발상/풀이), 개념과 문제를 잇는 별명 태그(정식 용어와 병기), 문제마다 메타 헤더(유형 라벨·출처·5단계 복습 체크칸), 풀이는 고정 순서 단계, 같은 유형 묶음 쉬운→어려운. 개념들 사이 "왜"와 연결을 강조. 단원 끝 "백지 설명 체크"와 요약표·OX로 약점 보완.

## C_시험역산형
> 대학 교양 기말시험(O/X·객관식·계산·서술형)에서 거꾸로 설계. 각 소단원을 "시험에서 이렇게 나온다"로 시작 → 반드시 외울 핵심 문장 → 공식 카드(언제 쓰는지 조건 포함) → 계산 절차 레시피 → 대표 예제(풀이 접기) → 함정 포인트(헷갈리는 쌍 비교표) → 서술형 답안 틀. 장 끝: 한 장 요약, 공식 판단 흐름도, 예상 문제 세트. 세 명세서의 장치 중 시험 대비에 효과적인 것만 골라 쓴다.

## D_혼합형
> 세 명세서 각각의 "강점 Top 5"와 "적용 규칙 10개"를 모두 비교해, 대학 교양 통계(개념·해석·계산이 섞인 과목)에 가장 잘 맞는 조합을 직접 설계한다. 예: 시발점의 유도→박스→REMARK 리듬 + 개때잡의 별명 태그·고정 풀이 순서·문제 메타 헤더 + 시험 대비 장치(요약·오개념 체크·서술형). 통계와사회 PPT의 특성(교수 슬라이드, 사례·해석 비중, 표 읽기)을 반영해 필요하면 새 장치도 만든다. 템플릿 파일 첫머리에 "어떤 교재의 어떤 장치를 왜 가져왔는지" 표를 넣어라.

## 결과
- 재사용 템플릿 4개 → [templates/](../templates/)
- 7장 샘플 4개(각 1,500~2,100줄) → 강의 내용을 담고 있어 레포에는 넣지 않음
