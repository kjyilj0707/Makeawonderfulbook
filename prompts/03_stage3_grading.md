# 3단계 — 블라인드 채점 (응시 4 + 감사 4 + 시험 채점 1)

지시서: [03_EVAL_BRIEF.md](03_EVAL_BRIEF.md). 핵심은 **만든 에이전트가 자기 결과를 채점하지 않게** 하는 것.

| 역할 | 수 | 볼 수 있는 파일 | 하는 일 |
|---|---|---|---|
| 응시자 (solver) | 형식당 1 | 그 형식의 샘플 1개 + exam.md **만** | 사전 지식 없이 샘플만 보고 12문항 풀이, 답마다 샘플 근거 위치 표시 |
| 감사자 (auditor) | 형식당 1 | rubric·concepts·샘플·원본 (exam 파일 금지) | 개념 99개 대조(누락), 원본과 다른 사실(정확성), 막히는 지점(이해 용이성), 장단점 |
| 시험 채점자 | 1 | exam_key + 답안 4개 + 샘플(근거 검증용) | 같은 기준으로 4개 채점, 근거가 허위면 0점 |

## 응시자 프롬프트
```
EVAL_BRIEF.md 의 "역할 1: 시험 응시자"를 수행하라. 담당 샘플 코드: D_혼합형.
규칙(읽어도 되는 파일 2개뿐)을 엄격히 지켜라. 최종 답: 답안 파일 경로와 "근거 없음" 문항 수.
```

## 감사자 프롬프트
```
EVAL_BRIEF.md 의 "역할 2: 감사자"를 수행하라. 담당 샘플 코드: D_혼합형 (샘플 파일 samples/sample_D_혼합형_7장.md).
```

## 시험 채점자 프롬프트
```
시험 답안 4개를 채점하라. 같은 기준으로 공정하게.
- 채점 기준: eval/exam_key.md, eval/rubric.md 의 시험 대비력 환산식
- 답안: eval/answers_<코드>.md 4개
- 필요하면 각 답안이 근거로 든 샘플 위치를 확인해 근거가 실제로 있는지 검증 (근거가 허위면 그 소문항 0점).
- 서술형(11, 12)은 채점 포인트별로 엄격하게.
출력: eval/exam_scores.md — 문항×형식 점수표, 총점/35, 환산(/30), 형식 간 차이가 난 문항과 이유.
최종 답: 네 형식의 점수와 "이 시험이 형식 차이를 변별했는가" 한 줄.
```
