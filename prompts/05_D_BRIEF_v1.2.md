## v1.2 보완 규칙 (D 감사 지적 + 공통 약점 — 템플릿보다 우선)
1. 장 머리에 **앞 장 기초** 블록(이 장에서 쓰는 앞 장 기호·개념 1~2줄씩, "→ 6장 6.2절"처럼 원본 절 번호로 안내) + **기호표**(기호 통일: 확률은 $P(\cdot)$, 표준정규 확률변수 $Z$·표 값 $z_{\alpha/2}$, 표본비율 $\hat p$ 등. 원본 혼용 표기는 기호표에만).
   - 이 교재는 6.2 정규분포 이후부터 시작하므로, 첫 장(6장 후반) 머리에는 6.2까지의 핵심(정규분포·표준화·표준정규분포표 읽기)을 **요약 블록**으로 짧게 넣는다 (원본 6장 p.6~14 근거, 출처 표기).
2. 정의 전 사용 금지. 분포표 값을 쓸 때는 "어느 표의 어느 칸인지" 밝힌다.
3. **별명 태그 장당 6개 이하**, 풀이 줄마다 다는 것이 아니라 **판정·근거가 되는 줄에만** (D 샘플은 태그가 너무 많아 시끄럽다는 지적). 부정확한 별명 금지 (예: 폭은 $1/\sqrt n$인데 "1/n"이라 하면 안 됨).
4. 같은 공식 전문은 [정리] 박스 1번 + 장 끝 요약표 1번만. 나머지는 "→ 개념 7-5 [정리]" 참조.
5. 원본에 없는 판단·해석은 `(교재 보충)` 표시. 새 사실·공식 금지. 그림 묘사는 원본 그림과 다르게 쓰지 말 것 (모르면 "[그림] 원본 그림 7-10 참고"로 구조만).
6. 원본 예제·그림·표 번호 그대로. 원본 오타·계산 불일치는 고치지 말고 원본 표기 블록 + "(직접 계산하면 …)".
7. 목표 분량: 원본 슬라이드 1장당 25~35줄.

## 마크업 규칙 (조판기가 이것만 인식한다 — 반드시 지킬 것)
Pandoc 마크다운 + fenced div. 수식은 `$...$`, `$$...$$` (LaTeX). `<details>` 쓰지 마라.

```
# 제7장 확률표본과 추정                                  ← 장 (파일당 1개)

:::
::: prereq                                               ← 앞 장 기초 블록
:::
::: symbols                                              ← 기호표 (마크다운 표)
:::

## 개념 7-1 확률표본과 통계량                             ← 개념(=원본 절). 조판에서 "Theme" 세로띠·대제목
::: map
표본 → **통계량** → 중심극한정리 → …                       ← 지도 한 줄, 현재 위치 굵게
:::
::: intro
상황 / 필요 / 할 것 3줄
:::

### THEME 01 확률표본                                    ← 소단원
::: question

::: summary title="확률표본의 정의"                      ← [정리] 박스 (노란 박스). 안에 ❶❷❸ 목록, 마지막 줄 "한 줄로: …"

**A가 아니라 B**
:::
::: tableread title="표 7-2 표본평균의 분포"               ← [표 읽기]: 표 재현 + 볼 점 ①②③

::: example label="예 7-3"                               ← 원본 예제(풀이 동봉, 본문 안에 표시)

:::

```
- 확인문제는 **각 개념(##) 끝에 모아서** 2~5개. 유형은 계산형/해석형/서술형.
- 장 끝: `## 시험 대비 팩` 아래 `### 요약표`, `### 분포표 값 모음`, `### OX`(문항은 번호 목록, 답은 ::: answer 하나에 모아서), `### 백지 설명`(질문 목록), `### 통합 서술형`(::: problem 으로), `### 원본 표기 확인 목록`(표), `### 슬라이드 대응표`(표: 원본 쪽 → 교재 위치) + 점검 결과 한 줄.
- fenced div는 `:::` 개수 맞추기 (중첩 시 바깥은 `::::`처럼 콜론을 더 써도 됨). 속성 값은 큰따옴표.
- 표는 파이프 표. 표 안에 수식 가능. 줄바꿈이 필요한 긴 셀은 피하라.
- 그래프는 그리지 말고 `::: figure title="그림 7-10 χ² 분포"` 안에 [그림] 구조 설명(축·모양·볼 점) — 조판에서 회색 그림 상자로 나온다.
- 이모지 쓰지 마라 (❶❷❸, ①②③, ★, ☐, ←, →, ⚠ 정도의 기호만).
