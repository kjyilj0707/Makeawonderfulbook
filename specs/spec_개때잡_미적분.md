## 0. 교재 한 줄 정체성

**강의를 그대로 옮긴 "판서 노트 + 바로 써먹는 기출 문제" 교재.** 개념을 '개념 NN'이라는 얇은 단위 35개로 쪼개고, 각 단위는 짧은 THEME 설명 → 시범예제 → 기출 문제(해설 자리를 일부러 한 칸 밀어 둠)로 끝난다. 정리 페이지나 연습문제 세트는 거의 없고, 반복 복습(5단계 복습)을 교재 밖 학습 습관으로 떠넘기는 구조다.

### 1-2. 계층
- **대단원(3개)**: Ⅰ 수열의 극한과 급수 / Ⅱ 미분법 / Ⅲ 적분법. 각 대단원 앞에 **간지 1장**(큰 로마숫자 그래픽 + 소속 개념 목록 2열). 간지 뒤 빈 면이 붙기도 함.
- **중단원 = "개념 NN"(35개, 권 전체 연번)**. 두 종류:
  - **일반 개념 단원**(18개): THEME 설명 + 시범예제 + 문제.
  - **취약유형 집중공략 단원**(17개): 설명이 거의 없거나 THEME 1개 + 바로 문제. 유형 이름이 곧 단원 이름(예: 도형과 극한, 합성함수의 미분가능성, f′(x)의 그래프).
- **소단원 = THEME 01, 02, …**(한 개념 안 2~6개). 개념 하나에 THEME가 몇 개든 문제는 **개념 단위로 한꺼번에** 뒤에 몰린다.
- 문제 번호는 **권 전체 연번 001~212 안팎**(개념당 평균 5~7문항, 개념25·26처럼 큰 단원은 6~15문항).

### 1-3. 단원 시작/끝 장치
- **시작**: 좌상단 "개념"이라는 작은 글자 + 큰 하늘색 숫자 + 제목(한 줄). 그 아래 도입 문단 1~3줄 또는 곧바로 THEME 01. 취약유형 단원은 숫자 대신 말풍선 모양 "취약유형 집중공략" 배지.
- 부정적분처럼 큰 단원은 도입부에 **"되는 놈/안 되는 놈" 2열 분류표**로 단원 전체 지도를 먼저 준다.
- **끝**: 별도 정리·요약·단원평가 없음. 마지막 문제의 풀이로 그냥 끝나고 다음 쪽(대개 홀수쪽)에서 새 개념 시작. 단원 끝 정리가 **없다**는 것이 이 시리즈 형식의 특징.
- 머리글(쪽 위): 짝수쪽 좌상단 "개념 NN 제목", 홀수쪽 우상단 "대단원명". 바닥글: 홀수쪽에 시리즈 슬로건 한 줄.

## 3. 개념 서술 방식

- **순서: 예시·현상 먼저 → 이름/정의 → 기호 → 결론 공식 → Tip.** 정의를 먼저 던지는 일은 드물다. 예) 수열 몇 개를 나열해 화살표로 결과를 보여 준 뒤 "이것을 ~라 한다"로 명명. 미적분판은 동기 질문 한 줄("결과는 뭘까?")로 THEME를 여는 경우가 많다.
- **문장 톤**: 강의 말투 그대로의 평서·구어 혼합("~다", "~자", "~보자", "~한다는 아이디어~"). 학생을 "여러분"보다 '우리'로 묶음. 감탄·강조("!!")가 Tip 제목에 등장.
- **문장 길이**: 짧다. 한 문단 2~4문장, 한 문장 1~2줄. 문단 사이 여백이 넓고, 줄마다 수식 한 줄이 끼어든다.
- **자문자답(소크라테스식) 장치**: 본문 안에서 질문 한 줄 → "아니다." 같은 짧은 반박 → 이유 → 다음 질문으로 이어 가는 계단. 정적분의 미분, ∞의 뜻처럼 **추상적 개념에서 특히 많이 쓴다**(미적분판에서 두드러짐).
- **비유·별명 붙이기**: 추상 규칙에 **짧은 별명**을 붙인다(예: ∞를 보는 두 시선, "무시하자 (1)(2)", 극한 아이디어 (1)(2)(3), 미분하고 싶은 마음/대입하고 싶은 마음 → 줄여서 '미분욕·대입욕', 겉함수·속함수 대신 겉/알맹이). 이 별명이 **문제 해설에 그대로 라벨로 재등장**한다 → 개념-문제 연결 장치.
- **증명/유도 처리(미적분판 특징)**:
  - 유도는 생략하지 않되 **"한 줄 = 한 변형"** 의 세로 등식 사슬로 짧게. 각 줄 오른쪽에 하늘색 손글씨풍 주석.
  - 유도 → 일반화 순서: 구체 예(숫자 상한/하한) → 문자로 일반화 → 이름 붙이기(샌드위치 정리 등) → ◎ 결과 줄로 정식화.
  - 구분구적법처럼 **그림이 곧 증명**인 곳은 [1단계]·[2단계] 절차 라벨 + 그래프 3장을 세로로 쌓고 아래 화살표로 "n을 키우면" 과정을 보여 준다.
  - 역연산 유도(미분 표 → 적분 표): 미분 화살표 목록을 먼저 보여 주고 "거꾸로 하면" 적분 목록이 되는 **화살표 표 2개 나란히** 방식.
  - 엄밀 증명(ε-δ 등)은 없음. 시험에 필요한 수준까지 "왜 그런지 납득"이 목표.
- **학생 질문 예상 장치**: ① 자문자답 문단 ② 알아두기 여백 메모(기호 읽는 법, 흔한 착각) ③ 머리말의 Q/A ④ 해설 안 손글씨 주석("~만 챙겨!" 같은 한마디). 별도 FAQ 박스는 없음.

## 4. 예제·문제 설계

- **종류 3층**
  1. **시범예제**: 공식 직후 1문항, 수능 형식이 아닌 "~을 구하시오" 직접 계산형. 풀이에 '설명(발상)' 칸을 따로 둬 **무엇을 보고 어떤 도구를 꺼내는지**를 먼저 한 줄로 말함. '교과서 풀이'·'다른 풀이'를 붙여 정석/요령을 비교.
  2. **감각 드릴**(일부): 같은 기술을 수십 번 손에 익히는 무해설 계산 목록 + 답만 있는 쪽.
  3. **기출 문제**: 평가원·교육청 실제 기출(출처 표기). 5지선다 또는 단답, 〈보기〉 ㄱㄴㄷ형 포함.
- **난이도 계단**: 개념 단원 안에서는 대략 쉬운 기출 → 복합 기출 순. 권 전체로는 "일반 개념 단원(기본 적용)" → "취약유형 집중공략 단원(심화 적용)"이 교대로 나오며 대단원 뒤쪽으로 갈수록 취약유형 비중이 커진다(적분법은 개념28~34 연속 7개가 취약유형).
- **풀이 표기**:
  - 등식 사슬을 세로 정렬, 한 줄 한 변형. 결론 줄 앞에 ∴ 또는 ⇒.
  - 하늘색 손글씨풍 **곁주석**(괄호/중괄호로 묶어 "왜 이 변형인지")과 **개념 라벨 태그**(하늘색 테두리 상자 안에 '미분욕', '대입욕', '극한 아이디어(1)' 등).
  - 단계 번호 ㉠㉡㉢으로 식을 붙잡아 두고 뒤에서 "㉠을 ㉡에 대입".
  - 답: 시범예제는 결과 옆 작은 "답" 칸, 기출은 오른쪽 아래 검은 "정답" 태그.
  - 해설 안 그래프: 풀이 중간에 해당 단계에서 필요한 그래프를 작게 직접 그려 넣음(그래프 해석형 문제의 핵심 장치).
- **문제-개념 연결 표시**: 문제 배지 맨 위에 개념/아이디어 이름 → 해설 안에서 같은 이름의 라벨 태그 → 독자가 THEME로 되돌아갈 수 있음. 별도의 "관련 개념 p.xx" 표기는 없다.
- **밀린 해설(시리즈 공통 핵심 장치)**: 문항 N의 풀이는 문항 N+1 아래에 놓이고, 개념의 첫 문항 아래에는 마지막 문항의 풀이가 온다. 풀다가 답이 눈에 들어오지 않게 하면서도 별책 해설 없이 한 권에 해설을 담는 방식. 각 문항 아래 공간은 원래 **직접 풀이를 쓰는 칸**이자 해설 칸.

## 5. 시각 장치

- **색 체계**: 사실상 2도(검정 + 하늘색). 하늘색 = 제목, 개념 번호, THEME 제목 밑줄, 형광펜식 강조, 손글씨 주석, 라벨 태그. 굵은 검정 = 핵심 용어. 빨강/주황은 앞부분 학습법 페이지에만.
- **박스 종류**
  | 박스 | 모양 | 용도 |
  |---|---|---|
  | Tip | 하늘색 바탕 사각, 왼쪽 위 "Tip" 꼬리표 | THEME 결론 압축 |
  | 시범예제 | 회색 가는 테두리 사각, 안에 '설명/풀이/교과서 풀이/다른 풀이' 검은 꼬리표 | 직후 적용 |
  | ◎ 결과 줄 | 박스 없음, ◎ 기호 + 굵은 소제목 | 공식 정식화 |
  | 알아두기 | 여백 단 메모(소제목+가는 선) | 보충·주의 |
  | 참고 | 작은 검은 꼬리표 박스, 해설 옆에 그림 포함 | 문제 풀이에 필요한 배경 공식(예: 내접원 넓이) |
  | 구름 말풍선 | 둥근 구름 테두리 | 암기 요령·부호 규칙 |
  | 타원 라벨 | 수식 아래 화살표로 연결된 타원 | 수식 부분의 이름 붙이기(겉/알맹이, 위끝·아래끝) |
- **아이콘**: 거의 없음. THEME 라벨 옆 작은 다면체(보석) 장식, 문제 번호 배경 다면체. 장식은 브랜드용이고 의미 체계는 색·꼬리표가 담당.
- **도식·그래프 사용법(미적분판에서 두드러짐)**
  - **변환 전 → 변환 후 2그림 + 굵은 화살표 + 화살표 위 조건 문구**: 그래프 압축·팽창, 삼각비 변 바꾸기 등.
  - **세로 3단 그림 + ↓**: 극한 과정(직사각형 분할이 촘촘해지는 모습).
  - **그래프 위 주석**: 접선 여러 개를 겹쳐 그리고 "기울기 증가/감소"를 휘어진 화살표로 표시해 이계도함수 부호를 시각화.
  - **식 ↔ 그림 대응 라벨**: 식의 부분(넓이 = ∫…)을 그래프의 색칠 영역에 선으로 연결.
  - **2열 화살표 표**: 미분 → / 적분 → 대응 목록.
  - 대부분 흑백 선화 + 하늘색 면 채우기. 축·눈금 최소화.
- **여백**: 매우 넉넉. 설명 쪽은 왼쪽 1/5이 여백 단(THEME 라벨, 알아두기). 문제 쪽은 한 쪽 한 문항이라 하단 절반 이상이 풀이 공간. 한 쪽 텍스트 밀도가 낮아 "판서 같은" 인상.

## 6. 복습·정리 장치

- **단원 끝 정리: 없음.** 대신 THEME마다 Tip 박스가 "미니 정리" 역할을 하고, 개념 머리의 분류표가 단원 지도 역할.
- **개념 체크: 없음**(OX, 빈칸 채우기 없음). 대신 "5단계 복습" 체크줄 1~5가 모든 문항에 달려 있어 **반복 횟수 기록**이 확인 장치.
- **학습법 자체를 복습 장치로 제시**: "빈 종이에 강의 재현하기", "풀이 단계마다 이유 말하기"가 앞부분에 명시 → 교재는 재현할 재료(짧은 판서)만 제공.
- **오개념 경고**: 별도 '주의' 아이콘 없음. 자문자답 반박 문장, 알아두기 메모, 구름 말풍선, "~는 무시해도 된다/안 된다" 대비, '부정형 두 가지'처럼 "되는 것/안 되는 것" 대비 표로 처리.
- **연결 개념 표시**: ① 별명 라벨이 개념 → 해설로 이어짐 ② "수학Ⅱ에서 배운 ~" 같은 선수 과목 한 줄 언급 ③ 미분 표를 거꾸로 읽어 적분 표 만들기처럼 **앞 단원 결과를 화살표 반전으로 재사용** ④ 같은 아이디어를 Ⅰ의 '도형과 극한 Ⅰ' → Ⅱ의 '도형과 극한 Ⅱ'처럼 대단원을 넘어 번호를 이어 붙임.

## 7. 이 교재만의 강점 Top 5 (미적분판에서 특히 두드러지는 것)

1. **별명 라벨 → 해설 재등장 루프.** 추상 규칙에 2~4글자 별명을 붙이고(미분욕·대입욕, 극한 아이디어(1)), 해설에서 그 별명을 하늘색 태그로 다시 달아 "이 줄은 그 개념"임을 보여 준다. 확통판보다 규칙이 많은 미적분판에서 훨씬 촘촘하다.
2. **유도를 '한 줄 한 변형 + 곁주석'으로 보여 주기.** 증명을 빼지도, 엄밀하게 늘이지도 않고 세로 등식 사슬과 옆 주석으로 "왜"를 붙인다. 계산 공식이 많은 단원에서도 공식이 어디서 왔는지 따라갈 수 있다.
3. **그래프 변환/극한 과정의 전→후 그림.** 2그림+화살표, 3단 세로 그림으로 "과정"을 보여 준다. 정적분 정의·넓이 같은 추상 개념을 그림 몇 장으로 납득시킨다.
4. **자문자답 계단.** "이건 뭘까? → 아니다 → 그러면?" 형식으로 학생의 오해를 먼저 꺼내고 깨는 문단. 정적분의 미분처럼 헷갈리는 개념에 집중 배치.
5. **밀린 해설 + 5단계 복습 체크줄 + 한 쪽 한 문항.** 별책 없이 한 권에서 "스스로 풀기 → 다음 쪽에서 확인 → 반복 기록"이 돌아간다. (시리즈 공통이지만 문항 수가 많은 미적분판에서 효과가 크다.)
   - 보너스: **감각 드릴 쪽**(답만 있는 계산 목록)으로 기술 숙련을 개념 설명과 분리.

## 8. 약점·통계와사회 교재화에 옮기기 어려운 점

- **강의 의존**: 판서식 짧은 서술은 강의를 들었다는 전제. 강의 없이 읽으면 연결 문장이 부족하다. → 통사 교재는 강의 녹음 없이 읽혀야 하므로 연결 문장을 더 넣어야 함.
- **단원 끝 정리·개념 체크 부재**: 기말 대비 교재에는 요약표와 자가 점검이 필수인데 원본에는 없다. 형식 그대로 쓰면 안 되고 보강해야 함.
- **기출 문제 의존**: 문제 블록 전체가 수능 기출 출처 표기에 기대고 있다. 통사는 기출 은행이 없고, BRIEF 원칙상 PPT 밖 문제를 새로 만들 수 없음 → PPT 예제만으로 문제 블록을 채워야 하므로 "개념당 6문항" 밀도를 낼 수 없다.
- **밀린 해설은 마크다운에서 의미가 약함**: 종이에서는 "다음 쪽에 있어 안 보임"이 장치지만 md에서는 `<details>` 접기가 같은 효과를 더 잘 낸다.
- **수치 해석·서술형 부재**: 미적분판은 계산 정답형 중심. 통계와사회는 "해석·판단·사례"(표본 편향, 신뢰구간 의미 해석)가 중요해 서술형 답안 모델이 필요한데 원본에 형식 예가 없다.
- **별명 붙이기의 위험**: 비공식 별명이 통계 용어(유의수준, 신뢰수준)와 섞이면 오히려 혼동. 별명은 정식 용어와 병기해야 함.
- **2색·여백 단 레이아웃**: md 단일 단에서는 여백 단(알아두기)을 그대로 재현할 수 없다 → 인용 블록으로 대체 필요.

## 9. "통계와사회 PPT를 이 형식으로 바꾼다면" 적용 규칙 10개

1. **번호 체계**: 장 → `개념 NN`(권 전체 연번) → `THEME NN`. 7장은 PPT의 소제목 하나 = THEME 하나, 서로 묶이는 THEME 2~5개 = 개념 하나. 헤더 형식: `## 개념 07 표본평균의 분포` / `### THEME 02 표본평균의 기댓값과 분산`.
2. **개념 머리 지도**: 각 개념 첫머리에 2열 비교표 1개(예: 모집단 ↔ 표본, 점추정 ↔ 구간추정, σ를 알 때 ↔ 모를 때). 이 표가 그 개념의 THEME 목록 역할을 한다.
3. **THEME 서술 순서 고정**: ① 동기 질문 1줄(`> 질문: …?`) → ② 작은 예/표/숫자 나열 → ③ "이것을 ○○라 한다" 정의 → ④ `◎` 결과 줄(LaTeX 블록 1~3줄) → ⑤ Tip 박스 → `[7장 p.N]`. 한 문단 2~4문장, 문장 1~2줄.
4. **Tip 박스**: THEME마다 정확히 1개, 1~2줄 압축(`> **Tip** …`). 공식이면 공식 1줄, 판단 규칙이면 "~이면 ~를 쓴다" 형태.
5. **알아두기(여백 메모 대체)**: 기호 읽는 법·용어 구분·흔한 착각은 본문에 섞지 말고 `> **알아두기**:` 인용 블록으로 분리(1~3줄). 여러 개면 THEME 끝에 몰기.
6. **자문자답 계단**: 추상 개념(표본분포, 신뢰수준의 의미, n-1)마다 최소 1회 "질문 → 흔한 오답 → '아니다' → 이유" 3~5줄 계단을 넣는다. 오답은 학생이 실제로 할 법한 해석으로, 이유는 PPT 범위 안에서만.
7. **별명 라벨 + 해설 재등장**: 판단 규칙에는 2~6글자 별명을 정식 용어와 병기해 붙이고(예: `【표준화】`, `【√n 효과】`), 예제·확인문제 풀이 줄 끝에 같은 라벨을 `【…】`로 달아 근거를 표시한다. 한 개념에서 라벨 3개 이하.
8. **유도는 한 줄 한 변형**: PPT에 있는 유도(표본평균의 기댓값·분산, 신뢰구간 식 변형)는 `aligned` 세로 등식으로, 줄마다 오른쪽에 `\quad\text{(← 이유)}` 곁주석 1개. PPT에 없는 증명은 추가하지 않는다.
9. **시범예제 → 확인문제 2층**: THEME 직후 `**시범예제**` 1문항(문제 / 발상 1줄 / 풀이 / 답, 풀이·답은 `<details>`), 개념 끝에 PPT 예제를 쉬운 순으로 배열한 `**확인문제 NNN**`(권 전체 연번). 각 문항 머리에 `[쓰는 개념: …] [출처: 7장 p.N]` 배지 줄과 `복습 □□□□□` 체크칸. 계산 반복이 필요한 곳(z값 읽기, 표준오차 계산)은 답만 있는 "감각 드릴" 표를 별도로.
10. **그림은 전→후 / 과정형으로**: 분포 변화(모집단 분포 → 표본평균 분포, n이 커질 때 폭이 좁아짐), 표준화(X → Z)는 "그림/표 A → 화살표(조건) → 그림/표 B" 형식으로 기술하거나 ASCII/표로 나란히 놓는다. 그리고 원본에 없는 보강으로 **개념 끝 1/2쪽 요약표**(공식·조건·해석 3열)와 **OX 3문항**을 반드시 붙인다(8절 약점 보완).
