## 0. 교재 한 줄 정체성

인강 강사의 수업을 그대로 따라가며 **"개념 짧게 → 기출문제로 바로 적용 → 같은 문제를 5번 다시 설명하며 복습"** 하도록 설계된 수능 대비 **강의 동반형 개념서 + 기출 적용 문제집**. 이론서라기보다 "개념 카드 + 대표 기출 풀이 노트"에 가깝고, 철학은 *이해한 것을 스스로 설명할 수 있을 때까지 반복(백지 복습)*.

- 앞부속: 표지 → 이벤트/광고 → 머리말(왜 이 책인가) → **교재 구성과 특징(3단계)** → **5단계 복습법 설명(2쪽)** → 강사 커리큘럼·등급별 추천 → 목차. 뒷부속: 표준정규분포표 1쪽.
- 분량 비중: 개념 설명 1~4쪽 : 문제 7~15쪽. 즉 **책의 80% 이상이 "문제 1개 = 1쪽" 페이지**.

### 1-2. 단원 시작/끝 장치
- **시작**: 개념 제목 바로 아래 2~4줄짜리 **도입 문단**(이 개념이 무엇이고 왜 필요한지 일상어로) → 곧바로 THEME 01.
- **끝**: 별도 요약·정리 페이지 **없음**. 마지막 문제 페이지 다음에 바로 다음 개념 제목이 나온다. 대신 아래 "해설 순환" 장치가 단원의 닫힘 역할을 한다.
- **해설 순환 배치(핵심 장치)**: 한 쪽에는 문제 N과 그 아래 **문제 N−1의 해설**이 실린다. 단원의 첫 문제 쪽에는 단원 **마지막 문제의 해설**이 실려 단원 안에서 고리처럼 닫힌다. (교재 표현: "해설이 한 문제씩 뒤로 이동") → 문제를 풀 때 바로 아래 답이 보이지 않게 하는 장치.

## 3. 개념 서술 방식

- **동기 → 정의 → 그림 → 의미 → 압축 공식** 순. 정의 앞에 1~3문장으로 "왜 필요한가/현실에서 어떤 모양인가"를 먼저 말한다(예: 정규분포는 "사회현상 대부분이 가운데 몰린다"는 관찰로 시작, 표본평균은 "전국 성인 키 조사" 상황으로 시작).
- **문장 톤**: 기본은 평서형 문어체("~이라 한다", "~이다")지만, 곳곳에 **강의 말투**가 섞인다 — "반드시 암기해 두도록 하자", "~라는 얘기다", 이야기체 도입("옛날 옛날에 ○○라는 사람이 살았는데…" 식으로 정리 이름을 소개). 문장 길이는 짧은 편(1~2줄).
- **비유·말장난 암기 장치**: 공식 옆 말풍선에 언어유희 구호(예: 표본평균 표준편차 = 루트 n으로 나눔을 말장난으로). 「 」 안의 한 줄 구호(표준화 = "자기 자신에서 평균 빼고 표준편차로 나눈다")를 Tip 박스에 넣는다.
- **그림 사용**: 개념당 1~3개. 그래프 위에 **청록색 손글씨 주석**(대칭, 넓이 0.5, 표준화 화살표). "일반 분포 → 표준화 → 표준정규분포"처럼 **두 그림을 화살표로 나란히** 놓는 변환 도식이 반복된다. 추정 단원은 구간을 **가로 막대 + 양쪽 같은 길이 A** 도식으로 반복 사용.
- **증명/유도**: 엄밀 증명 없음. 필요한 경우 **식을 한 줄씩 변형하는 짧은 유도**(예: 표본평균 확률 0.95 식 → m에 대한 범위로 뒤집기)만 보여주고 "이를 토대로 다음과 같이 쓴다"로 공식 박스에 연결. 계산이 필요한 사실(분포표 값 등)은 "표를 참고한다"로 처리.
- **학생 질문 예상 장치**: 본문 중 명시적 Q&A 박스는 거의 없음(머리말의 복습법 페이지에만 Q/A 형식 1회). 대신 ① 그림 주석 말풍선이 "왜?"에 답하고(예: 넓이가 1이 되어야 하는 이유), ② 해설 속 **청록색 옆주석**이 "이 단계에서 무엇을 썼는지"(표준화했다, 대칭 이용 등)를 적어준다. ③ "~이 아니라 ~로 나눠야 한다" 식의 **대비 문장**으로 흔한 오해를 미리 차단.

## 4. 예제·문제 설계

- **종류**: (a) 개념 직후 "시험예제"(기본, 일부 단원만), (b) 본 문제 = **실제 수능·평가원·교육청 기출**(출처 표기), (c) 출처 없는 자체 문제(일부, 주로 경우의 수·취약유형), (d) 빈칸 채우기형 "과정 추론" 문제(㈎㈏㈐), (e) 〈보기〉 ㄱㄴㄷ 판단형.
- **난이도 계단**: 사이드바 **유형 라벨**로 묶는다 — 같은 유형 라벨 문제 3~5개(단순 계산) → 다음 라벨(역산·컷라인·대소 관계) → 마지막은 고배점 4점 문항. 즉 "유형 블록 단위로 쉬움→어려움". 배점(3점/4점)도 출처 줄에 표기되어 난이도 지표 역할.
- **풀이 표기**:
  - 첫 줄에 **확률변수 정의 문장**("~을 확률변수 X라 하면")으로 시작 → 따르는 분포 명시 → 표준화 → 표 값 대입 순의 **고정 스크립트**.
  - 단계는 줄바꿈 + `⇒`, `∴`로 연결. 연립이 필요하면 ㉠㉡ 표시.
  - 여러 경우는 (i)(ii)(iii) → "(i)~(iii)에 의해".
  - 풀이 방법이 둘이면 "방법 (1) – ○○ / 방법 (2) – ○○"로 병기.
  - 핵심 단계 옆 **청록색 주석**(어떤 공식·성질을 썼는지), 수식 아래 작은 그래프로 확률 영역을 색칠.
  - 답은 **우하단 검은 "정답" 라벨**. 시험예제는 답 끝에 "답" 아이콘.
- **문제–개념 연결**: 사이드바 유형 라벨 + 페이지 머리의 "개념 NN : 제목"으로 어떤 개념의 적용인지 항상 표시. 문제 번호는 책 전체 연번이라 강의(“25번부터 30번까지”)와 바로 대응.

## 5. 시각 장치

| 장치 | 모양 | 용도 |
|---|---|---|
| 개념 헤더 | 회색 원호 + 큰 숫자 + 콜론 + 제목 | 중단원 시작, 이후 매 짝수쪽 머리에 축소 반복 |
| THEME 띠 | 초록 체크박스 아이콘 + "THEME —— 0N" | 소단원 |
| 왼쪽 세로 민트 띠 | 개념 설명 쪽에만 있는 연한 세로 컬러 바 | "여기는 개념 페이지" 신호(문제 쪽엔 없음) |
| ◎ 핵심 박스 | 민트 배경, ◎ 기호 제목, 번호 목록 | 정의·공식·성질 요약 |
| Tip 박스 | 회색 배경, 작은 초록 "Tip" 태그 | 공식 1줄 + 암기 구호 |
| 공식 단독 박스 | 민트 띠 중앙에 기호만(예: 분포 표기) | 꼭 외울 기호 하나 강조 |
| 시험예제 박스 | 얇은 테두리 + 상단 탭 라벨, 안에 검은 "풀이" 라벨 | 기본 적용 |
| 조건 박스 | 문제 안 ㈎㈏ 조건을 연민트 둥근 박스로 | 조건 분리 |
| 형광 하이라이트 | 민트 형광 + 굵게 | 새 용어 첫 등장 |
| 청록 손글씨 주석 | 가는 화살표 + 작은 청록 글씨 | 그림·풀이의 "왜" 설명 |
| 말풍선 | 둥근 테두리 말풍선 | 공식 옆 의미·말장난 암기 |
| 취약유형 배지 | 원형 배지 + 큰 제목, 개념 헤더와 다른 모양 | 특수 단원 |
| 사이드바 카드 | 둥근 사각, 번호 크게, 아래 1~5 줄 | 문제 메타정보 + 복습 체크 |

- **색 체계**: 사실상 **민트/청록 1색 + 검정 + 회색**. 색은 "강조(용어)·요약(박스)·주석(손글씨)" 세 의미만 가진다. 아이콘은 체크박스(THEME), 폴더(해설), 검은 라벨(정답·풀이) 정도로 최소.
- **도식**: 통계 파트는 ① 종 모양 곡선 + 색칠 영역 + 경계값 라벨, ② 표준화 전/후 곡선 2개를 화살표로 연결, ③ 신뢰구간 가로 막대(가운데 표본평균, 양쪽 같은 폭), ④ 여러 표본의 신뢰구간을 세로로 쌓아 일부만 모평균을 포함함을 보이는 그림, ⑤ 모집단→여러 표본 화살표 다이어그램(지도 비유).
- **여백**: 개념 쪽 아래 1/4~1/3이 비어 있음(필기용). 문제 쪽은 문제 아래 풀이 공간 확보. 사이드바 1~5칸은 복습 기록 공간.

## 6. 복습·정리 장치

- **5단계 복습 체크칸**: 모든 문제에 1~5 칸. 앞부속 2쪽에서 방법을 설명 — 수업 직후 교재 개념 읽기 → **빈 종이에 강의를 재현하며 소리 내어 설명** → 풀이의 각 단계에 "왜 그렇게 했는지"까지 설명 → 1·2주 간격으로 5회 반복. 이 책의 **유일하고 강력한 복습 장치**.
- **해설 순환 배치**: 답이 바로 아래 있지 않아 "먼저 풀고 넘겨서 확인"을 강제.
- 단원 끝 요약 / 개념 체크 퀴즈 / 마인드맵: **없음**. 요약은 각 THEME 안의 ◎ 박스·Tip 박스가 대신함.
- **오개념 경고**: 별도 "주의" 박스는 없고, ① 본문의 대비 문장("X가 아니라 X̄이면 분모가 달라진다"), ② 취약유형 집중공략 단원(자주 틀리는 구조를 따로 모음)으로 처리.
- **연결 개념 표시**: "앞서 배운 바와 같이", "THEME 01에서 알아본" 처럼 **앞 THEME·앞 개념을 문장으로 호출**. 다음 단원 예고는 없음. 개념 순서 자체가 사슬(확률분포표→이항분포→확률밀도함수→정규분포→이항→정규 근사→표본평균→추정)로 짜여 있어 각 도입문이 직전 개념을 이어받는다.

## 7. 이 교재만의 강점 Top 5

1. **"문제 1개 = 1쪽" + 유형 라벨 사이드바**: 문제마다 유형 이름·출처·배점·복습칸이 붙어 있어, 문제를 "유형 카드"처럼 관리할 수 있다.
2. **해설 순환 배치**: 해설을 한 문제씩 뒤로 밀고 단원 안에서 고리로 닫는 레이아웃 — 바로 답을 보지 못하게 하는 물리적 장치.
3. **5단계(설명형) 복습 시스템**: "백지에 강의를 재현해 설명"하는 메타인지 복습을 교재 구조(체크칸)로 박아 넣음.
4. **변환 도식의 반복**: 표준화(일반→표준), 이항→정규, 표본평균의 분포를 매번 "두 그림 + 화살표"로 같은 모양으로 보여줘 시각적 패턴이 생긴다. 신뢰구간도 같은 가로막대 도식을 개념·풀이에서 끝까지 재사용.
5. **풀이의 고정 스크립트 + 청록 옆주석**: "확률변수 정의 → 분포 → 표준화 → 표 값" 순서를 모든 풀이에서 똑같이 반복하고, 각 줄 옆에 근거를 적어 풀이를 "따라 말할 수 있는" 형태로 만든다. 여기에 **취약유형 단원**으로 오답 패턴을 별도 공략.

## 8. 약점 / 대학 교양 통계(통계와사회) 교재화 시 옮기기 어려운 점

- **강의 의존형**: 개념 설명이 매우 짧고(1~3쪽), 나머지는 강사 강의가 메운다는 전제. 강의 없이 읽는 교양 교재로는 설명 밀도가 부족하다 → 우리 교재는 개념부를 더 두껍게 써야 함.
- **기출 문제 풀(pool)이 핵심인데 통계와사회엔 기출이 없다**: 문제 대부분이 수능 기출이라 "유형 라벨 + 출처 + 배점" 체계가 그대로는 성립하지 않음. PPT 예제·교수 제시 문제로 대체해야 하고 수가 적다.
- **계산 중심 vs 해석 중심**: 이 책은 확률값 계산·역산이 목표. 통계와사회는 표본추출, 신뢰구간의 **의미 해석**, 사회 데이터 사례 등 서술형 이해가 중요 → 문제 유형을 해석형·서술형으로 바꿔야 함.
- **요약·체크 장치 부재**: 단원 끝 정리/개념 확인 퀴즈가 없어 그대로 따라 하면 기말 직전 복습용으로 약하다 → 다른 벤치마크 교재(시발점 등)의 정리 장치로 보완 필요.
- **지면 레이아웃 의존 장치**: 사이드바 카드, 해설 순환(쪽 넘김), 손글씨 주석, 형광펜은 마크다운(.md)에서 그대로 재현 불가 → `<details>` 접기, 인용 블록, 굵게/표로 근사해야 함. 해설 순환은 "다음 문제 아래 이전 해설" 대신 접기로 대체하는 것이 현실적.
- 말장난 암기 구호는 대학 교재 톤과 어긋날 수 있음(절제해서 1단원 1~2개 정도로).

## 9. "통계와사회 PPT를 이 형식으로 바꾼다면" — 적용 규칙 10개

1. **계층 고정**: `# 개념 NN : 제목`(장 내 연번, 예: 7장 → 개념 01~0k) → `## THEME 0N 소제목`. PPT 슬라이드 묶음 하나(정의 1개 + 공식 1개 수준)를 THEME 하나로 매핑한다. 취약 개념(예: 신뢰구간 해석, 표준오차 vs 표준편차)은 `# [취약유형 집중공략] 제목` 단원을 따로 만든다.
2. **개념 도입 3줄 규칙**: 각 `# 개념` 바로 아래 3~5줄 도입문 — "현실 상황 1문장 → 그래서 무엇이 필요한가 1문장 → 이 단원에서 할 것 1문장". PPT 범위 밖 사실은 넣지 않는다.
3. **THEME 내부 순서 고정**: ① 정의 문단(새 용어는 `**굵게**` 첫 등장 1회) → ② 그림/도식(가능하면 ASCII 또는 이미지 자리표시) → ③ 의미 해석 2~4줄 → ④ `> ◎ 핵심` 인용 블록(번호 목록 공식) → ⑤ `> **Tip**` 한 줄 공식 + 「암기 구호」 → 끝에 `[7장 p.N]`.
4. **변환 도식 표준화**: "X → Z 표준화", "모집단 → 표본 → X̄의 분포", "X̄ ± A 구간"은 매번 **같은 모양의 도식**(같은 표기·같은 화살표)을 재사용한다. 예: `N(μ, σ²) ──표준화──▶ N(0,1)`, `[ X̄−A ─── X̄ ─── X̄+A ]  길이 2A`.
5. **대비 문장으로 오개념 차단**: THEME마다 필요한 곳에 "○○가 아니라 △△이다" 형식의 문장 1개를 넣고 앞에 `⚠ 혼동 주의`를 붙인다(예: 모집단 표준편차와 표본평균의 표준편차 비교).
6. **시험예제 블록**: THEME 끝에 기본 적용 1문제 — `**시험예제**` 문제 / `<details><summary>풀이</summary>` 풀이 `</details>` / `**답**`. PPT 예제가 있으면 그것을 우선 배치.
7. **문제 카드 메타 헤더**: 각 문제 위에 한 줄 표 `| 유형: 모평균 신뢰구간 계산 | 문제 007 | 출처: 7장보충 p.N | 난이도 ★★ | 복습 ☐☐☐☐☐ |`. 같은 유형 라벨끼리 묶고 ★ 순으로 배열(유형 블록 단위 계단).
8. **풀이 고정 스크립트**: 모든 통계 풀이를 "① 확률변수/모수 정의 → ② 따르는 분포 명시 → ③ 표준화 또는 공식 대입 → ④ 표 값 → ⑤ 결론 문장(해석 포함)"으로 쓴다. 각 줄 끝에 `← 근거(표준화, 대칭 등)` 주석을 붙인다. 경우 나눔은 (i)(ii), 연립은 ㉠㉡.
9. **해설 지연 장치**: 풀이는 기본 접힘(`<details>`), 정답은 풀이 맨 끝 `**정답** ○` 한 줄. (선택) 단원 문제를 다 낸 뒤 해설을 모아 두는 대신, 이 책처럼 "문제 N 아래에 N−1 해설"을 두는 순환 배치는 md에선 혼란스러우므로 쓰지 않는다.
10. **5단계 복습 + 설명형 체크**: 교재 앞에 5단계 복습법 1쪽(설명하며 복습, 간격 반복)을 두고, 각 `# 개념` 끝에 `### 백지 설명 체크` 3문항(“이 공식의 각 기호가 무엇인지 말해 보라”, “왜 √n으로 나누는가” 같은 **설명 요구형** 질문, 답은 접기)을 둔다 — 원본 교재에 없는 정리 장치를 이 형식의 철학(설명할 수 있어야 안다)으로 보완.
