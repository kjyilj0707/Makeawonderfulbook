## 0. 교재 한 줄 정체성
인강(현우진)과 함께 쓰는 **"개념 강의 교재"**. 교과서보다 개념을 한 층 깊게 파고, 개념 설명은 본책에 다 쓰되 예제 풀이는 비워 두어 **강의를 듣고 손으로 직접 푸는 것**을 전제로 한다. 철학: "공식 암기보다 구조(왜 그런지)와 문제에서 쓰는 관점을 먼저 정리한다."

## 1. 전체 구조
- **계층**: Chapter(대단원 3개: 경우의 수 / 확률 / 통계) → **Theme**(중단원, 0~22번 일련번호, 책 전체 통번호) → 번호 소제목 `1.` `2.` `3.`(소단원) → `1)` `2)`(세부 항목).
- 통계 파트 = Chapter 3, Theme 15~22(이산확률변수와 확률분포 / 기댓값·표준편차 / 이항분포 / 연속확률변수·확률밀도함수 / 정규분포 / 표본평균의 분포 / 모평균 추정 / 모비율 추정). Theme 하나는 5~25쪽(정규분포가 가장 길어 약 25쪽, 모평균 추정은 약 7쪽).
- **단원 시작 장치**
  - Chapter 표지: 전면 노랑 배경, 큰 숫자, 그 장의 Theme 목록과 시작 쪽.
  - Theme 첫 쪽: 별도 표지 없이 바로 본문. Chapter 3의 첫 Theme은 **전체 흐름도**(이산/연속 두 갈래로 "확률변수 → 함수 → 분포표/그래프 → 대표 분포"를 화살표로 이은 지도)를 맨 위에 두고 "이 순서로 공부하며 큰 틀을 기억하라"는 안내문으로 시작한다. 같은 흐름도가 정규분포 Theme 첫머리에서 **현재 위치를 박스로 표시해 다시 나온다**(지도 재등장).
- **단원 끝 장치**
  - Theme 끝: 그 Theme의 예제(번호 01~15 등)를 모아 두는 문제 구역.
  - 2~3개 Theme 묶음마다 **STEP UP** 구역(회색 세로띠 "STEP UP / Theme 18~19" 식 표기). 여러 Theme을 섞은 통합·고난도 문제 6~8개, 2문제/쪽, 풀이 공간 넓음.
  - 책 끝: MEMO 쪽, 빠른 정답.
- **상시 장치(모든 쪽)**: 왼쪽(짝수쪽) 바깥 여백에 굵은 노랑 세로띠 + 세로쓰기 "Theme N 단원명" — 현재 위치를 항상 보여 준다. 쪽 하단에 쪽번호와 장 이름.

## 2. 소단원 1개의 블록 순서
(Theme 19 정규분포, Theme 21 모평균 추정 기준. 한 Theme 안에서 아래 ①~⑧이 소단원 수만큼 반복된 뒤 ⑨가 몰려 나옴)

| 순서 | 블록 이름(내가 붙인 이름) | 역할 | 분량 | 레이아웃 위치 |
|---|---|---|---|---|
| ① | 소단원 제목 `1. ○○○` | 소단원 시작 | 1줄 | 노랑(주황) 큰 글씨, 단 상단 |
| ② | 세부 항목 `1) ○○` | 하위 개념 단위 | 굵은 1줄 | 제목 아래 |
| ③ | 도입·유도 서술 | 상황(현상/실험)에서 출발 → 식 전개 → 정의 문장으로 도착. 핵심 용어는 **굵게** | 0.3~1쪽 | 본문 단, 오른쪽에 작은 그래프/도식 병치 |
| ④ | `[참고]` | 기호의 유래, 정의역·공역 같은 곁가지 사실 | 1~3줄 | 주황 라벨, 본문 흐름 안 |
| ⑤ | 핵심 정리 박스 | "이상을 정리하면 다음과 같다" 한 줄 뒤, **노랑 테두리 박스**에 공식/성질을 ❶❷❸ 번호로 압축 | 3~8줄, 그래프 포함 시 반쪽 | 단 폭 전체 |
| ⑥ | `REMARK 1, 2, 3…` | 박스 내용을 **문제 풀이용 관점**으로 재해석: 왜 그런지, 대칭 활용법, 흔한 오해, 용어의 의미 | 개당 3~15줄, 소단원당 2~5개 | 검은 바탕 흰 글씨 라벨 + 굵은 제목 1줄 + 들여쓴 본문 |
| ⑦ | `[예1] [예2]…` (본문 속 예) | REMARK/박스를 바로 적용하는 짧은 계산 예. **풀이가 바로 붙어 있음**(→ 화살표로 결론) | 3~10줄 | 본문 흐름 안, 표준정규분포표 조각이 오른쪽에 붙음 |
| ⑧ | Note 칸 | 소단원/개념부가 쪽 중간에서 끝나면 남는 공간을 연노랑 필기 박스로 채움 | 반쪽 내외 | 쪽 하단 |
| ⑨ | `예제 01~NN` | Theme 끝에 모은 연습 문제. **풀이 없음**, 큰 빈칸 | 2문제/쪽(일부 4문제/2쪽) | 노랑 원형 큰 번호 배지 + 문제문, 아래 여백 |
| ⑩ | STEP UP | 여러 Theme 통합 | 6~8문제 | 회색 세로띠 쪽 |

※ 확률 파트(Theme 10~11)도 동일 패턴: 소제목 → 서술 → 노랑 박스 → REMARK → [예] → Note → 예제 01~08. 즉 책 전체 공통 템플릿.

## 3. 개념 서술 방식
- **동기 → 정의 순서**. 정의를 먼저 던지지 않는다. 실제 현상(키·몸무게 분포 같은 것)이나 단순 실험(동전 던지기)의 구체 사례를 먼저 보여 주고, "이와 같이 …를 ○○라 한다"로 정의에 도착한다.
- **유도는 본문에서 끝까지 한다**. 신뢰구간처럼 공식이 있는 개념은 표준화 → 부등식 변형 → 결론을 줄 단위로 전개하고, 그 결과만 박스에 요약한다. 증명 생략 대신 "식 한 줄 + 의미 한 줄"이 번갈아 나옴.
- **톤**: 기본은 교과서식 평서문(…이다, …한다). REMARK와 참고에서만 약간 구어체("~해 두자", "~라고 생각하면 좋다", "너무나 당연한 얘기지만") — 강사의 목소리가 이 부분에만 들어간다.
- **문장 길이**: 짧다(대부분 1~2줄). 한 문장 한 사실. 접속은 "이때", "즉", "따라서", "이상을 정리하면".
- **비유·그림**: 문학적 비유는 거의 없다. 대신 **그래프로 말한다** — 같은 개념을 조건별로 나란히 그린 작은 곡선 그림(σ 변화, m 변화, 넓이 같음/다름을 음영으로). 수식 아래에 작은 주석 글씨(예: "z축 평행이동", "표준편차의 배수")를 화살표에 붙여 변환 과정을 설명.
- **학생 질문 예상 장치**: REMARK 제목이 사실상 "학생이 헷갈리는 지점"의 목록이다(예: 왜 표준화하나 / Z값은 무슨 뜻인가 / 모표준편차 대신 표본표준편차를 써도 되나 / 신뢰구간의 정확한 의미). 일부 REMARK는 빈칸(□)을 두고 "몇 배인가?"를 스스로 채우게 하는 질문형.
- 오해 교정: 신뢰도 해석처럼 학생이 잘못 말하기 쉬운 해석을 REMARK에서 "~가 아니다"로 명시적으로 부정.

## 4. 예제·문제 설계
- **3단계 문제층**
  1. 본문 `[예N]`: 개념 직후, 풀이 동봉, 1단계 적용(계산 확인용).
  2. `예제 NN`: Theme 끝, 풀이 없음, 교과서 응용~수능 3·4점 수준. 번호가 올라갈수록 어려워지고 뒤쪽은 5지선다 + 표준정규분포표 동봉 실전형.
  3. `STEP UP`: Theme 2~3개 통합, 고난도, 풀이 없음.
- **난이도 계단**: [예]는 공식 대입 1~2단계 → 예제 앞번호는 개념 하나 역적용(미지수 구하기) → 예제 뒷번호는 다른 단원(이항분포·독립시행 등)과 결합 → STEP UP은 여러 개념 복합.
- **풀이 표기([예] 한정)**: 단계 번호 없이 식을 세로로 정렬해 내려 쓰고, 결론 줄 앞에 `∴` 또는 `⇒`. 식 옆에 짧은 이유 주석(→ "○○ 대신 사용"). 답은 마지막 줄.
- **예제는 풀이·답 없음** → 본책은 "문제집"이 아니라 강의 판서용. 답은 책 끝 정답표.
- **개념-문제 연결 표시**: 명시적 태그(예: "→ REMARK 2")는 없다. 대신 문제가 바로 앞 소단원 뒤에 위치하는 근접성으로 연결. 필요한 수치표(정규분포표 조각)를 문제 옆에 작은 표로 붙임.

## 5. 시각 장치
- **색 체계**: 노랑(주조색) + 검정 + 회색 3색 체계.
  - 노랑: Theme 세로띠, 소단원 제목, 핵심 정리 박스 테두리, 예제 번호 배지, Note 칸 배경(연노랑).
  - 검정: REMARK 라벨(검정 바탕 흰 글자).
  - 주황 글씨: `[참고]` 라벨.
  - 회색: STEP UP 세로띠, 표 머리행.
- **박스 종류**
  | 장치 | 모양 | 용도 |
  |---|---|---|
  | 핵심 정리 박스 | 노랑 테두리 사각형, 왼쪽 위 노랑 막대 + 제목 | 정의·공식·성질 요약(❶❷❸ 번호) |
  | REMARK n | 검정 라벨 + 굵은 제목 | 해석·관점·주의 |
  | [참고] | 주황 텍스트 라벨, 박스 없음 | 곁가지 정보 |
  | [예n] | 대괄호 라벨, 박스 없음 | 본문 속 풀이 예 |
  | 예제 NN | 노랑 원 배지 + 큰 숫자 | 연습 문제 |
  | Note | 연노랑 면 + 연필 아이콘 | 필기 공간 |
  | 수치표 조각 | 회색 머리행 2열 작은 표 | 문제/예 옆 우측 정렬 |
- **도식·그래프**: ① 단원 흐름도(화살표 체인), ② 조건 비교 그래프(같은 축에 2~3개 곡선), ③ 음영 넓이 그림 + "=" "+" 기호로 그림끼리 등식 표현(그림 방정식), ④ 집합 대응도(원 두 개와 화살표), ⑤ 신뢰구간 여러 개를 세로로 늘어놓은 막대 그림. 그래프는 작고(가로 1/4~1/3 단), 본문 오른쪽에 병치.
- **여백**: 개념부는 2단 펼침에서 빽빽하지 않게 행간 넓음. 예제부는 문제당 반쪽~1/4쪽 빈칸(풀이 공간). 쪽이 남으면 반드시 Note 칸.

## 6. 복습·정리 장치
- **소단원 내부 정리**: "이상을 정리하면" → 노랑 박스. 정리 장치가 단원 끝이 아니라 **유도 직후**에 있다.
- **구조 지도 재등장**: 장 첫머리 흐름도가 다음 Theme 시작에서 현재 위치 표시와 함께 다시 나온다(앞뒤 연결).
- **연결 개념 표시**: REMARK에서 앞 단원 개념을 끌어와 "다시 한번 강조하지만 …는 원래 이산이다" 식으로 연결(이항분포 → 정규근사). 별도 아이콘은 없음.
- **오개념 경고**: 별도 "주의" 박스는 없고 REMARK가 겸한다.
- **개념 체크 문항/단원 요약 쪽**: 없음. 복습은 예제와 STEP UP이 담당.

## 7. 이 교재만의 강점 Top 5
1. **REMARK 층** — 공식 박스 다음에 "이 공식을 문제에서 어떻게 보라"는 관점 해설을 번호 매겨 2~5개 붙인다. 정의(무엇)와 관점(어떻게 쓰나)을 물리적으로 분리.
2. **유도 → 박스 압축의 리듬** — 길게 유도한 다음 반드시 박스로 접는다. 읽을 때는 흐름, 복습할 때는 박스만 훑으면 된다.
3. **그림 방정식** — 음영 넓이 그림끼리 =, +로 이어 대칭·확률 관계를 시각적으로 증명.
4. **전체 지도 + 상시 위치띠** — 장 첫머리 흐름도와 모든 쪽의 Theme 세로띠로 "지금 어디를 공부하는지"를 잃지 않게 함.
5. **풀이 있는 [예] / 풀이 없는 예제의 분리** — 보고 배우는 문제와 직접 푸는 문제를 구분하고, 직접 푸는 문제에는 넉넉한 손풀이 공간.

## 8. 약점·통계와사회 교재화에 옮기기 어려운 점
- **강의 의존**: 예제 풀이가 없다. 독학용 기말 교재에는 그대로 쓰면 안 됨 → 풀이를 `<details>`로 넣어야 함.
- **입시 문제 중심**: 예제 대부분이 "미지수 a 구하기", 5지선다 계산형. 통계와사회는 해석·사회적 맥락(여론조사, 표본 편향, 신뢰구간 해석) 서술형 비중이 커서 문제 유형을 바꿔야 함.
- **사회적 사례 부족**: 도입 사례가 짧고 수학적. 교양 통계는 실제 데이터·뉴스 사례가 동기 역할을 해야 함(단, PPT 범위 안에서만).
- **개념 체크/요약 쪽 부재**: 기말 직전 복습용 1쪽 요약이 없음 → 교재화 시 추가 필요(형식 요소로).
- **종이 레이아웃 의존**: 2단 병치 그래프, 세로 위치띠, 노랑 색면은 마크다운에서 재현 불가 → 이모지 없는 라벨·인용 블록·표로 대체해야 함.
- **고교 범위의 단순화**: t분포, 표본분산의 n−1 같은 대학 내용이 없어 이 책의 REMARK 목록을 그대로 쓸 수 없음. REMARK 주제는 PPT에서 새로 뽑아야 함.

## 9. "통계와사회 PPT를 이 형식으로" 적용 규칙 10개
1. **계층 규칙**: `# 제7장` → `## Theme N. 소주제명`(장 전체 통번호) → `### 1. 소단원` → `#### 1) 항목`. Theme 하나 = PPT의 한 주제 묶음(슬라이드 5~15장).
2. **지도 규칙**: 장 첫머리에 개념 흐름도 1개(텍스트 화살표 `모집단 → 표본 → 통계량 → 표본분포 → 추정`). 각 Theme 시작에 같은 지도를 다시 쓰고 현재 위치를 **굵게** 표시.
3. **도입 규칙**: 모든 소단원은 정의가 아니라 PPT 속 사례·상황 또는 도입 질문 1개("왜 ~일까?")로 시작하고, 2~5줄 뒤 "이런 것을 **○○**라 한다"로 정의에 도착.
4. **유도 규칙**: PPT에 있는 유도·식 변형은 생략하지 않고 한 줄 식 + 한 줄 의미를 교대로 쓴다.
5. **박스 규칙**: 유도 끝에 반드시 "이상을 정리하면" 한 줄 + 인용 블록 박스 `> **[정리] 제목**` 안에 ❶❷❸(①②③) 번호로 공식/성질 압축. 박스 끝에 `[7장 p.N]`.
6. **REMARK 규칙**: 박스 다음에 `**REMARK 1. 제목(한 줄 질문/주장형)**` 2~4개. 주제는 (a) 왜 그런가 (b) 기호·값의 의미 (c) 흔한 오해의 부정 (d) 앞 단원과의 연결 중에서 고른다. PPT 범위를 넘는 새 지식 금지.
7. **참고 규칙**: 기호 유래, 용어 영어명, 곁가지는 `*[참고]*` 한두 줄로 본문과 분리.
8. **예 규칙(보고 배우기)**: 각 REMARK/박스 직후 PPT 예제를 `**[예1]**`로 넣고 풀이를 바로 보이게(접지 않음), 결론 줄은 `∴`로 시작, 옆 주석은 `← 이유`.
9. **예제 규칙(직접 풀기)**: Theme 끝에 `### 예제` 구역, `**예제 01**` 번호제, 쉬운 것 → 해석/서술형 → 통합 순. 각 문제는 문제 / `<details><summary>풀이</summary>` / `<details><summary>답</summary>`로 분리, 필요한 분포표 값은 문제 아래 작은 표로 동봉. 2~3 Theme마다 `## STEP UP (Theme a~b)` 통합 문제 3~6개.
10. **위치·여백 규칙**: 각 소단원 머리에 `> Theme N · 소단원명` 위치줄(세로띠 대체), 소단원 끝에 `> ✎ Note:` 빈 인용 블록 3줄(필기 공간). 장 끝에는 이 책에 없는 보완으로 "박스만 모은 1쪽 요약" + REMARK 제목 목록(오개념 체크리스트)을 둔다.
