# 형식 템플릿 B — 개때잡형 (개념 연번 + THEME + 별명 태그 + 문제 카드)

> 근거 명세: spec_개때잡_확통.md, spec_개때잡_미적분.md (보조: spec_시발점.md의 요약 장치)
> 철학: **"짧게 정의하고 → 바로 써 보고 → 남에게 설명할 수 있을 때까지 반복한다."**
> 한 장(章)을 `개념 NN`이라는 얇은 단위로 쪼개고, 모든 문제·풀이에 개념의 **별명 태그**를 다시 달아 개념과 문제를 잇는다.

## 1. 장 전체 골격 (순서 고정)

| 순서 | 블록 | 내용 |
|---|---|---|
| 0 | 장 머리 | `# 제N장 제목 — 개념때려잡기형` + 범위·출처 한 줄 |
| 0-1 | 사용법 | 5단계 복습 요약(5줄) + 회차 체크표 |
| 0-2 | 개념 지도 | 개념 01~NN을 화살표 사슬(ASCII)로. 각 화살표 위에 "왜 다음 개념이 필요한가" 한 구절 |
| 0-3 | 별명 태그 사전 | 표: `【별명】 · 정식 용어 · 한 줄 뜻 · 처음 나오는 개념` |
| 1~NN | `# 개념 NN : 제목` 반복 | 아래 2절 |
| 취약 | `# [취약유형 집중공략] 제목` | 장 안에서 가장 헷갈리는 판단(분포 선택, 기호 구분)을 표 + 판정 문제로 |
| 끝 | 장 끝 장치 | 요약표(공식·조건·해석) → OX → 백지 설명 종합 → 별명 색인 → 원본 표기 확인 목록 → 슬라이드 대응표 |

- **개념 번호**: 장 안 연번 `개념 01~`. PPT의 소절 1개 ≈ 개념 1개, 소절이 길면 2개로 나눈다. 보충 자료는 이어지는 번호로 붙인다.
- **문제 번호**: 장 전체 연번 `문제 001~` (강의·복습 때 "015번부터"처럼 부르기 위해).

## 2. 개념 1개의 블록 순서

```
# 개념 NN : 제목                       [7장 p.a–b]
도입 3~5줄 (상황 → 그래서 무엇이 필요한가 → 이 개념에서 할 일)
↪ 연결: 앞 개념의 무엇을 이어받는지 1줄 ("왜"를 말한다)
## THEME 01 소제목
  ① 정의 문단 (새 용어 첫 등장만 **굵게**, 영어 병기)
  ② [그림] 구조 설명 / ASCII 도식 / 마크다운 표 (원본 그래프의 축·모양·라벨 포인트 모두)
  ③ 해석 2~4줄 + (추상 개념이면) 자문자답 계단 Q → 흔한 오답 → "아니다" → 이유
  ④ > ◎ 핵심  (번호 목록, 공식 LaTeX)
  ⑤ > **Tip** 공식 한 줄 + 「암기 구호」 + 【별명】(=정식 용어)
  ⑥ (필요 시) > ⚠ 혼동 주의: "A가 아니라 B" 한 문장
  ⑦ [7장 p.N]
  ⑧ (원본 오타가 있으면 바로 아래) > ⚠ 원본 표기: …
## THEME 02 … (①~⑧ 반복)
### 시범예제 (원본 예제 우선)        ← 문제 / 발상 / <details>풀이</details> / 답
### 문제 카드 NNN …                  ← 3절
### 백지 설명 체크                     ← 3문항, 답은 접기
```

### 블록별 규칙
- **도입**: PPT에 나온 상황·예만 사용. 새 사실 금지. 3~5줄.
- **↪ 연결**: 모든 개념에 1줄 필수. "앞에서 ○○ 때문에 막혔다 → 그래서 이 개념" 형식으로 *왜* 다음 개념이 필요한지를 말한다.
- **◎ 핵심**: 인용 블록, 번호 목록 3~6줄. 복습 때 ◎만 훑어도 공식이 다 보이게.
- **Tip**: THEME당 정확히 1개. 구호는 「 」, 장 전체에서 말장난은 2~3개 이하.
- **별명 태그**: 2~8글자, 반드시 `【별명】(=정식 용어)`로 첫 등장 시 병기. 한 개념에 새 별명 3개 이하. 같은 별명을 **풀이 줄 끝 근거 주석**에 그대로 재사용한다.
- **유도**: PPT에 있는 유도만. `aligned` 세로 등식, 한 줄 한 변형, 줄 끝 `\quad(\leftarrow \text{이유})`.
- **그림**: `[그림 번호] 제목` + 축·곡선 모양·색칠 영역·라벨 숫자를 글로 모두. 변환은 `A ──조건──▶ B` 같은 모양을 장 전체에서 재사용.

## 3. 문제 설계

### 문제 카드 메타 헤더 (모든 문제)
```
| 유형 | 문제 NNN | 출처 | 난이도 | 별명 | 복습 |
|---|---|---|---|---|---|
| 모평균 신뢰구간(σ 앎) | 020 | 7장 p.31 | ★ | 【뼈대 공식】 | ☐☐☐☐☐ |
```
- 출처: 원본 예제는 `7장 p.N`, 원본 수치를 바꾸거나 개념만으로 만든 문제는 `자체(7장 p.N 개념)`.
- 배열: **같은 유형 라벨끼리 묶고 ★ → ★★ → ★★★** (유형 블록 단위 계단).
- 형식: **문제** → `<details><summary>발상</summary>`(어떤 개념·별명을 꺼내는지 1줄) → `<details><summary>풀이</summary>` → `**답**` (답도 풀이 안에 두지 말고 따로 접기).

### 풀이 고정 스크립트 (통계 추정 문제 공통)
1. **정의**: 모수·확률변수·주어진 값 정리 (n, x̄, s, σ, p̂ …)
2. **분포 선택**: 어떤 분포를 쓰는지 + 근거(σ 앎/모름, n>30 등) ← 【별명】
3. **공식 뼈대**: 기호 공식 한 줄
4. **표 값·대입**: 표 값(Z, t, χ²)과 계산
5. **결론 문장**: 구간 + 의미 해석 한 문장

각 줄 끝에 `← 근거` 주석. 경우 나눔은 (i)(ii), 연립은 ㉠㉡.

### 문제 종류 (개념당 2~5개)
계산형(공식 대입) / 역산형(n, d 구하기) / 표 읽기형(분포표·원본 표) / 해석·서술형(신뢰구간 의미, 추정량 선택) / 유도 빈칸형(㈎㈏㈐).

## 4. 장 끝 장치 (원본 교재의 약점 보완)
1. **요약표**: `개념 | 공식 | 조건 | 해석·주의` 4열, 개념당 1~2행.
2. **OX 10~15문항**: 흔한 오해 위주, 답·이유는 접기.
3. **백지 설명 종합**: 개념당 1문항 "빈 종이에 설명해 보라", 모범 설명은 접기.
4. **별명 태그 색인**: 별명 → 정식 용어 → 쓰이는 문제 번호.
5. **원본 표기 확인 목록**: 본문의 모든 `⚠ 원본 표기`를 한 표로.
6. **슬라이드 대응표**: 원본 쪽 → 개념/THEME/문제 (누락 자체 점검용).

## 5. 노션 변환 시 주의
- `<details><summary>` → 노션 토글로 변환된다. **토글 안에 토글을 넣지 않는다**(발상/풀이/답은 나란히 둔다).
- `> ◎ 핵심`, `> **Tip**`, `> ⚠` 인용 블록은 노션에서 콜아웃으로 바꾸면 좋다(◎=민트, Tip=회색, ⚠=노랑).
- 수식: 인라인 `$…$`, 블록 `$$…$$`. 블록 수식 안에서 한글은 `\text{}`로 감싼다. `aligned`는 노션에서 지원됨.
- 메타 헤더 표는 6열 이하로 유지(노션 표 폭).
- ASCII 도식은 코드 블록(```)에 넣어 정렬을 지킨다.
- 체크칸 ☐는 노션 할 일 블록으로 바꿔도 된다.
