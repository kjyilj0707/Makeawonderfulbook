# 템플릿 C_시험역산형 — "기말시험에서 거꾸로 설계한 교재"

> 설계 원리: 대학 교양 기말시험(O/X·객관식·계산·서술형)에 **나올 형태**를 먼저 정하고, 그 문제를 맞히는 데 필요한 것만 그 순서대로 배치한다.
> 독자는 통계 배경이 거의 없는 1학년. 본문 근거는 강의 PPT뿐(새 사실·공식 금지). 직관 설명·연결 문장·연습문제는 형식 요소로 허용.
> 벤치마크에서 가져온 장치: 장 첫머리 지도 + 위치줄(시발점), "~가 아니라 ~이다" 대비 문장·고정 풀이 스크립트·문제 메타 헤더·복습칸(개때잡 확통), 자문자답 계단·근거 라벨·감각 드릴(개때잡 미적분). 그 밖의 장치(말장난 구호, 밀린 해설, 그림 방정식 등)는 시험 효과가 낮아 쓰지 않는다.

## 1. 장 전체 골격 (순서 고정)

| 순서 | 블록 | 내용 규칙 |
|---|---|---|
| 0 | `# 제N장 제목` + 한 줄 사용법 | "각 소단원은 ①→⑦ 순서. 시험 전날에는 장 끝 [한 장 요약]만" |
| 1 | **출제 지도** | 코드블록 화살표 흐름도(개념 사슬) + 표: 소단원 / 나올 유형(OX·객관·계산·서술) / 중요도 ★~★★★ / 출처 쪽. |
| 2 | `## N.k 절 제목` → `### N.k-A 소단원` | PPT 절 번호를 그대로 쓴다(교수 슬라이드와 대응). 소단원 = 정의 1개 + 공식 1~2개 수준. |
| 3 | 소단원마다 ①~⑦ 블록 | 아래 2절 |
| 4 | **장 끝 ⓐ 한 장 요약** | 시험 직전용. 공식 표(공식·조건·해석 3열) + 외울 문장 목록 + 숫자(임계값) 표. 1쪽 이내. |
| 5 | **장 끝 ⓑ 공식 판단 흐름도** | "무엇을 묻나 → 무엇을 아나 → n은 얼마나 → 어떤 공식" 결정 나무(코드블록) + 같은 내용 표. |
| 6 | **장 끝 ⓒ 예상 문제 세트** | O/X 10~12 → 객관식 5~6 → 계산 5~6 → 서술형 3~5. 각 문항 메타 헤더 + 풀이·답 접기. |
| 7 | **장 끝 ⓓ 오답 체크리스트 / 원본 표기 목록** | 함정 포인트 제목 모음 + 원본 오타(⚠) 모음. |

## 2. 소단원 블록 ①~⑦ (순서 고정, 해당 없는 블록은 "생략" 한 줄 없이 건너뛰되 ①②⑥은 필수)

맨 위 **위치줄**: `> 위치: 7.2 중심극한정리 › **표본평균의 분포** › 점추정 …` (현재 소단원 굵게)

| 블록 | 제목 표기 | 규칙 |
|---|---|---|
| ① 시험에서 이렇게 나온다 | `#### ① 시험에서 이렇게 나온다` | 이 소단원에서 나올 문항 꼴 2~4개를 **유형 라벨 + 실제 문제 줄기**로. 예: `[O/X] 통계량은 확률변수이다.` `[계산] σ를 알 때 95% 신뢰구간을 구하라.` 정답은 여기서 주지 않는다(②~⑦을 읽으면 풀리게). |
| ② 반드시 외울 문장 | `#### ② 반드시 외울 문장` | PPT 정의를 **시험 답안에 그대로 쓸 수 있는 1문장**으로. 번호 목록, 핵심 용어 **굵게**, 영어명 병기. 문장 수 2~6개. PPT 표현을 최대한 유지(바꿔 말하면 정의가 변질됨). |
| ③ 공식 카드 | `#### ③ 공식 카드` | 표 4열: **공식 / 언제 쓰나(조건) / 기호 뜻 / 주의**. 조건 열이 핵심(예: "정규모집단, σ 모름, n≤30"). 유도가 PPT에 있으면 카드 아래 `<details><summary>유도(PPT)</summary>`에 한 줄 한 변형 + `\text{(← 이유)}`. |
| ④ 계산 절차 레시피 | `#### ④ 계산 레시피` | 번호 단계 3~6개. 고정 스크립트: ❶ 주어진 값 정리(n, x̄, s 또는 σ, 신뢰수준) → ❷ 공식 고르기(판단 흐름도 해당 가지) → ❸ 표 값 찾기 → ❹ 오차(±부분) 계산 → ❺ 구간/값 → ❻ 결론 문장. |
| ⑤ 대표 예제 | `#### ⑤ 대표 예제` | **PPT 예제를 번호·문구 그대로**(`**[예 7-9]**`). 문제 / `<details><summary>풀이</summary>` / `**답**`(답도 `<details><summary>답</summary>`). 풀이 각 줄 끝에 근거 라벨 `【레시피 ❸】` `【공식카드: σ 앎】`. PPT가 생략한 중간 계산은 채워 넣되 PPT 숫자를 바꾸지 않는다. |
| ⑥ 함정 포인트 | `#### ⑥ 함정 포인트` | **헷갈리는 쌍 비교표**(2~3열: A / B / 구별 기준) 1개 + `⚠ 혼동 주의: ~가 아니라 ~이다` 대비 문장 1~3개. 추상 개념이면 자문자답 계단 1개(질문 → 흔한 오답 → "아니다" → 이유, 3~5줄). |
| ⑦ 서술형 답안 틀 | `#### ⑦ 서술형 답안 틀` | 예상 서술 문항 1개 + 빈칸 틀(`(1) 정의: ___ (2) 조건: ___ (3) 결론: ___`) + 모범답안 접기. 채점 키워드를 굵게. 계산 소단원은 "결론 문장 틀"(예: "( )% 신뢰수준 하에서 모평균은 ( )와 ( ) 사이에 있다고 믿을 수 있다"). |
| 출처 | 블록 끝 | `[7장 p.N]`, `[7보충 p.N]` — ②③⑤ 블록마다 끝에 단다. |

## 3. 문제 설계 규칙

- **메타 헤더**(장 끝 문항): `| 유형: 계산·모평균CI | 난이도 ★★ | 관련: 7.5-B | 복습 □□□ |` 한 줄 표.
- 층위: ⑤ 대표 예제(PPT 원본, 보고 배움) → 장 끝 예상 문제(원본 개념만으로 풀리는 새 숫자, 직접 풂).
- O/X는 ⑥ 함정 표의 각 행에서 1문항씩 뽑는다(함정 = 출제 포인트). 틀린 진술은 "범위/대상/조건 바꿔치기"로 만든다.
- 객관식은 공식 카드의 **조건 열**을 묻는다(어떤 공식/분포/자유도).
- 계산은 레시피 단계 그대로 풀이를 쓰고, 마지막 줄은 결론 문장.
- 서술형은 ⑦ 틀을 재사용하며 모범답안에 **채점 키워드** 굵게.
- 분포표 값이 필요하면 문항 아래 작은 표로 동봉(PPT에 나온 값만 사용).
- 풀이·답은 항상 `<details>`로 접는다.

## 4. 표기 규칙

- 수식 LaTeX(`$…$`, `$$…$$`). 신뢰구간은 $\left(a,\ b\right)$ 꼴로 PPT와 같게.
- 그림은 `[그림 7-6] 무엇` + 구조 설명 2~4줄 또는 ASCII/표.
- 원본 오타·불일치는 고치지 않고 바로 아래 `> ⚠ 원본 표기: …` 한 줄(가능하면 올바른 계산값 병기).
- 이모지 대신 텍스트 라벨(①~⑦, ❶~❻, 【 】, ⚠ 한 기호만).
- 소단원 하나 분량 목표: 1~2쪽. 외울 문장과 공식 카드가 소단원의 40% 이하로 압축되게.

## 5. 노션 변환 시 주의

- `<details><summary>…</summary>` → 노션 **토글**로 변환됨. 토글 안에 또 토글을 넣지 않는다(풀이와 답은 형제 토글로).
- `$$…$$`는 블록 수식, `$…$`는 인라인 수식으로 변환. `\begin{aligned}`는 블록 수식 안에서만.
- 표 안 수식은 인라인 `$…$`만 쓰고 `|` 문자는 `\mid` 또는 `\lvert`로 피한다.
- 흐름도는 코드블록(```text)으로 — 노션이 공백 정렬을 유지한다.
- `> 인용`은 노션 인용/콜아웃으로 변환. 위치줄·⚠ 원본 표기는 인용 블록 유지.
- 헤더는 `#`~`####` 4단계까지만(노션 제목 3단계 + 굵은 문단).
