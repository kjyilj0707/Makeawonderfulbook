# 템플릿 D_혼합형 — "유도·박스·REMARK + 별명 태그·고정 풀이 + 시험 대비 팩"

> 대상: 대학 교양 통계(개념·해석·계산이 섞인 과목), 교수 강의 PPT가 원본인 경우.
> 한 줄 철학: **읽을 때는 흐름(유도→박스→REMARK), 풀 때는 같은 순서(고정 스크립트+태그), 시험 전에는 팩만.**

## 0. 장치 출처표 — 어떤 교재의 어떤 장치를 왜 가져왔나

| # | 장치(이 템플릿 이름) | 가져온 교재·원래 장치 | 왜 통계와사회에 맞나 | 바꾼 점 |
|---|---|---|---|---|
| 1 | 장 지도 + 위치줄 | 시발점: 장 첫머리 흐름도, 모든 쪽의 Theme 세로띠 | 7장처럼 "표본→통계량→분포→추정"이 사슬인 장은 지금 위치를 잃기 쉽다 | 세로띠 → 개념마다 `> 지도:` 한 줄, 현재 위치 **굵게** |
| 2 | `개념 7-k` / `THEME 0n` 2층 번호 | 개때잡(확통·미적분): 개념 NN → THEME | PPT의 절(7.1…)·소제목(1. 2. …)과 1:1로 맞물려 강의와 바로 대응 | 권 전체 연번 대신 "장-절" 번호 (PPT 절 번호 그대로) |
| 3 | 개념 도입 3줄 | 개때잡 확통: 개념 제목 아래 2~4줄 도입 | 통계 배경이 없는 1학년에게 "왜 배우나"를 먼저 | 상황 → 필요 → 이 개념에서 할 것, 정확히 3줄 |
| 4 | 개념 머리 비교표 | 개때잡 미적분: 단원 앞 2열 분류표 | 통계는 "σ를 알 때/모를 때", "점/구간"처럼 갈래가 핵심 | 비교할 갈래가 있는 개념에만 |
| 5 | 도입 질문 → 사례 → 정의 | 시발점: 현상에서 출발해 정의에 도착 + 미적분: THEME 여는 동기 질문 | 교양 통계는 사례(여론조사·실험)가 동기 역할 | 사례는 PPT 안에서만 |
| 6 | 유도 한 줄 한 변형 + 곁주석 | 시발점: 유도는 본문에서 끝까지 / 미적분: 세로 등식 사슬 + 옆 주석 | n−1, 신뢰구간 뒤집기처럼 "왜"가 시험에 나온다 | `aligned` + `\text{← 이유}` |
| 7 | `[정리]` 박스 ❶❷❸ | 시발점: "이상을 정리하면" → 노랑 박스 | 복습 때 박스만 훑으면 됨 | 마지막 줄 `한 줄로:` 가 개때잡 Tip 역할을 흡수 |
| 8 | REMARK n | 시발점: 박스 뒤 관점 해설 2~5개 | 교양 통계의 핵심은 공식보다 **해석·오해 교정** | 주제를 (a)왜 (b)기호 뜻 (c)오해 부정 (d)연결로 고정 |
| 9 | 자문자답 계단 | 개때잡 미적분: 질문→"아니다"→이유 | 추상 개념(통계량도 확률변수, 신뢰수준)의 오해를 먼저 꺼내 깸 | REMARK 안의 한 형식으로 |
| 10 | ⚠ 혼동 주의 | 개때잡 확통: "A가 아니라 B" 대비 문장 | 표본 크기 vs 개수, σ vs σ/√n 같은 쌍 개념이 많다 | 한 줄, 굵은 대비 |
| 11 | 별명 태그 `【…】` | 개때잡 미적분: 별명 라벨이 해설에 재등장 | 풀이 줄마다 근거 개념이 보여서 "설명할 수 있는" 풀이가 됨 | 정식 용어와 병기, 개념당 3개 이하 |
| 12 | 고정 풀이 스크립트 | 개때잡 확통: 확률변수 정의→분포→표준화→표 값 | 구간추정 문제는 조건 판정이 승부 → 매번 같은 5단계 | ⑤ 결론을 **해석 문장**으로 끝냄 |
| 13 | `[예]` = PPT 예제 | 시발점: 본문 속 [예], 풀이 동봉 | PPT 예제는 반드시 전부 보존해야 함 | 풀이는 접기, 스크립트·태그 적용 |
| 14 | 문제 카드 메타 헤더 + 복습칸 | 개때잡 확통: 사이드바(유형·번호·출처·복습 1~5) | 유형별로 묶어 반복 관리 | 출처 대신 "근거 THEME", 난이도 ★ |
| 15 | 해설 지연 | 개때잡: 밀린 해설 | 바로 답을 보지 않게 | md에서는 `<details>` 접기로 대체 |
| N1 | **[표 읽기]** (신규) | — | 통사 PPT는 표·그래프(표본 표, 히스토그램, 분포 비교)가 많고 시험에 "표를 보고 판단" 문항이 나온다 | 표 재현 + 볼 점 3개 |
| N2 | **[해석 틀]** (신규) | — | 신뢰구간·추정치의 결론을 서술형 문장으로 써야 함 | 빈칸형 문장 틀 1개 |
| N3 | **(PPT 강조)** 표시 (신규) | — | 교수가 슬라이드에서 굵게 처리한 말 = 출제 신호 | 본문 해당 어구 뒤에 붙임 |
| N4 | **[공식 고르기]** 흐름 (신규) | — | 같은 모수라도 조건에 따라 공식이 갈림 | 질문 사슬 → 공식 |
| N5 | **시험 대비 팩** (신규, 세 교재 공통 약점 보완) | 시발점·개때잡 모두 단원 요약·개념 체크 없음 | 기말 직전 복습용 | 장 끝 6종(아래 4절) |

가져오지 않은 장치: 해설 순환 배치(md에서 혼란), 감각 드릴(통사는 계산 반복량이 적음 → 팩의 "분포표 값 모음"으로 대체), Note 빈칸(노션에선 의미 약함), 말장난 구호(대학 교재 톤 — 별명 태그로 대체), STEP UP(→ 팩의 "통합·서술형"으로 흡수).

## 1. 장 머리 (장마다 1회)
1. `# 제N장 제목` + 출처 범위 한 줄.
2. **장 지도**: 텍스트 화살표 1줄(개념 순서). 이후 각 개념 머리에 같은 지도를 `> 지도:` 로 다시 쓰고 현재 개념만 **굵게**.
3. **이 장의 태그 목록** 표(태그 | 정식 내용 | 처음 나오는 곳) — 풀이에서 보게 될 별명을 미리 공개.
4. 원본 예제 번호 중복·누락이 있으면 여기서 한 줄로 알린다.

## 2. 개념(=PPT 절) 블록 순서
`## 개념 N-k 절 제목` → ① `> 지도:` → ② 도입 3줄(상황 / 필요 / 할 것) → ③ (갈래가 있으면) 비교표 → ④ THEME 반복 → ⑤ 확인문제 카드 2~5개.

### THEME(=PPT 소제목) 블록 순서 — 고정
| 순서 | 블록 | 규칙 |
|---|---|---|
| ① | `### THEME 0n 제목` | PPT 소제목 그대로 |
| ② | `> 질문:` | 이 THEME가 답할 질문 1줄 |
| ③ | 사례 → 정의 | PPT 사례·상황 2~4줄 → "이것을 **용어**(영어)라 한다". PPT가 굵게 한 말 뒤엔 *(PPT 강조)* |
| ④ | 유도(있을 때만) | `aligned` 세로 사슬, 줄마다 `\text{← 이유}`. PPT에 없는 증명 추가 금지 |
| ⑤ | `> **[정리] 제목**` | ❶❷❸ 번호. 인라인 수식만. 마지막 줄 `한 줄로:` + 이 THEME의 태그 `【…】` 정의 |
| ⑥ | `**REMARK n. 질문/주장형 제목**` | 1~3개. 형식: 서술 / 자문자답 계단(질문→흔한 오답→"아니다"→이유) / `⚠ 혼동 주의: A가 아니라 B` |
| ⑦ | `[표 읽기]` | PPT에 표·그래프가 있으면 반드시. 표 재현(또는 `[그림]` 구조 설명) + "볼 점" ①②③ |
| ⑧ | `[예 N-m]` | PPT 예제 전부, PPT 번호 그대로. 문제는 펼침, 풀이는 `<details>`, 답은 별도 줄 |
| ⑨ | 출처 | 블록 끝 `[7장 p.N]` / `[7보충 p.N]` |
| — | `> ⚠ 원본 표기: …` | 원본 오타·불일치는 고치지 않고 바로 아래 한 줄 |

## 3. 문제 설계
- **고정 풀이 스크립트(추정·분포 문제 공통)**
  ①대상: 무엇을 추정/계산하나(모수·추정량) → ②판정: 조건(σ 앎? n>30? 정규모집단? 비율?) → 쓸 분포 → ③재료: $\bar x, s, \hat p, n$, 자유도 → ④대입: 표 값 + 공식 → ⑤결론: **[해석 틀]** 문장. 각 줄 끝에 `【태그】`.
- **문제 카드 헤더**(표 1행): `| 유형 | 번호 C7-xx | 근거 THEME | 난이도 ★~★★★ | 복습 ☐☐☐☐☐ |`
- **유형 3종을 개념마다 섞기**: 계산형 / 해석형(표·그림 보고 판단) / 서술형(이유 설명). 같은 유형끼리 묶고 ★ 순.
- **새 문제의 범위**: 그 장 PPT의 개념·공식과 **PPT에 등장한 분포표 값만** 쓰도록 수치를 설계(예: z=1.645/1.96/2.57).
- 풀이 `<details><summary>풀이</summary>`, 그 아래 `**답**`도 `<details><summary>답</summary>`.

## 4. 장 끝 — 시험 대비 팩 (6종, 이 순서)
1. **1쪽 요약표**: 개념 | 공식·조건 | 해석 한 줄 | 태그 (박스만 모은 것).
2. **[공식 고르기] 흐름**: 질문 사슬로 어떤 공식을 쓸지.
3. **분포표 값 모음**: PPT에 나온 z·t·χ² 값만 (감각 드릴 대체).
4. **오개념 OX 10문항**: REMARK에서 뽑음, 답·이유 접기.
5. **백지 설명 체크 5문항**: "~를 남에게 설명해 보라"(개때잡 5단계 복습 철학), 모범 설명 접기.
6. **통합·서술형 2~3문항**: 사례 해석 + 계산 결합, 모범답안 + 채점 포인트.

## 5. 노션 변환 시 주의
- `<details>` → 노션 토글. `<summary>` 안에는 수식 넣지 말 것. `<details>` 다음 줄은 비우고 본문 시작(안 비우면 마크다운이 안 풀림).
- 인용 블록(`>`) 안에는 **인라인 수식만**. 블록 수식 `$$`는 인용 밖에 둔다(노션에서 인용 속 수식 블록이 깨짐).
- 표 안 수식에 `|` 금지 → `\lvert`, `\mid` 사용. 표 칸에 블록 수식 금지.
- ❶❷❸, 【】, ⚠, ★, ☐ 는 일반 문자라 그대로 옮겨진다. 이모지 대신 이 기호만 쓴다.
- 제목 단계는 `#`~`###` 까지만 목차로 잡힌다 → THEME까지 `###`, REMARK·[예]는 굵은 글씨.
- 페이지 분할: 개념 하나 = 노션 하위 페이지 하나, 시험 대비 팩은 별도 페이지.
