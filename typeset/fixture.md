### THEME 01 확률표본

::: question
표본을 어떻게 뽑아야 '확률표본'이라 부를 수 있을까?
:::

확률변수 $X$가 특정 확률분포를 따를 때, 이 분포로부터 각각 독립적으로 관측된 $n$개의 표본을 **확률표본**(random sample)이라 한다.

$$
\begin{aligned}
E(\bar X) &= E\Big(\tfrac{1}{n}\textstyle\sum X_i\Big) && \text{← 정의}\\
&= \tfrac{1}{n}\textstyle\sum E(X_i) = \mu && \text{← 기댓값의 선형성}
\end{aligned}
$$

::: summary title="확률표본의 정의"
❶ $X_1,\dots,X_n$은 서로 **독립**이다.

❷ 모두 **같은 분포**를 따른다.

한 줄로: 확률표본 = 독립 + 동일분포 【i.i.d.】
:::

::: remark title="통계량도 확률변수인가?"
그렇다. 표본을 다시 뽑으면 값이 달라지므로 통계량도 확률변수이다.
:::

::: caution
**표본의 크기($n$)가 아니라 표본의 개수**를 늘리는 것이 아니다.
:::

::: tableread title="표 7-2 표본평균의 분포"
| 표본 | 평균 |
|---|---|
| 1 | 0.31 |
| 2 | 0.29 |

① 표본마다 평균이 다르다. ② 평균들의 평균은 모평균에 가깝다.
:::

::: example label="예 7-3"
균일분포 $U(0,1)$에서 크기 12인 표본을 뽑을 때 $\bar X$의 평균과 분산을 구하라.

::: solution
①대상: $\bar X$의 평균·분산 ②판정: 확률표본 → 【분산 n분의1】 ③재료: $\mu=1/2$, $\sigma^2=1/12$, $n=12$ ④대입: $Var(\bar X)=\dfrac{1/12}{12}=\dfrac{1}{144}$ ⑤결론: 평균 $1/2$, 분산 $1/144$.
:::

::: answer
답: $E(\bar X)=\tfrac12$, $Var(\bar X)=\tfrac1{144}$
:::
:::

::: interp
"표본평균은 평균 ___, 분산 ___ 인 분포를 따르며, $n$이 커질수록 ___ 에 가까워진다."
:::

::: pick title="모평균 신뢰구간 공식 고르기"

3. 아니면 → $t(n-1)$
:::
